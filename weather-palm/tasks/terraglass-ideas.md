## 他的机制清单（按标题推断），对照我们已有的

| 主题 | 他有 | 我们现状 |
|---|---|---|
| 沙 | 休止角固定、湿沙能堆更陡（沙堡）、过筛、楼梯滑落、雪崩 | 有休止角、雨让湿沙塌（**方向相反**：真实是微湿沙更稳、泡透才塌） |
| 水 | 真实流动、挖坑渗水、切一刀放干湖、冲出峡谷后停住、河自己冲出三角洲 | 有地表水流 / 积 / 漫 / 渗 / 冲沙；没有三角洲沉积、没有地下水 |
| 岩浆 | 越冷越稠，堆成塔不成河；倒进海；冲冰湖；瀑布浇岩浆 | 有冷却成石、遇水冒汽；粘度不随温度变 |
| 酸 | 溶解各种方块（排了榜）、能挖多深 | 没有 |
| 火 | 为什么烧光一片林子却在下一片熄灭；房子从外往里烧；草地烧后长回 | 有顺风 / 湿度 / 燃料；刚加了残骸生命周期 |
| 雷 | 雷劈沙子（→ 雷击玻璃）；避雷针 | 有劈山尖、固氮；**没有劈沙成玻璃** |
| 生物 | 兔子游走、气味（狐狸留味）、踩出小路、蚂蚁、蜜蜂筑巢、螃蟹建王国、青蛙、老兔子洞塌方、一只兔子一年吃多少草 | 8 种动物有吃 / 逃 / 躲雨；**没有气味场、没有踩出的路** |
| 季节 | 快入冬了、池塘怎么结冰 | 有雪、结冰道具；没有季节 |
| 技术 | 每格 1 字节、挖不卡、慢机自动降配、存档不卡、"没有物理引擎" | 网格模拟 + 实例化；没有自动降配 |
| 定位 | 桌面电子宠物缸 / 屏保 / "老板以为我在做表" | 我们是"掌心里的世界"（眼镜 + 手势），这是我们独有的 |

## 可以搬进掌心气象台的（按 性价比 排）

1. **动物踩出小路 + 气味场**（涌现，最出圈的一类）：动物走过的格子草被踩倒、多走几次变土路；捕食者留下会衰减的气味，兔子闻到就绕开。纯 sim.js 数据，画面上就是草地上慢慢出现的小径。
2. **雷劈沙子成玻璃**（雷击石）：闪电落在沙上，沿着往下长出一根玻璃管。matter.js 已有 glass 层，几十行。
3. **湿沙更稳**：微湿的沙休止角变大（能堆沙堡），泡透才塌——修正我们现在"一下雨就塌"的单向规则，更符合真实。
4. **岩浆越冷越稠**：粘度随温度变，倒得慢就堆成塔、倒得快才成河。
5. **河口三角洲**：水流变慢处把带的沙放下来。
6. **实验场景当分享素材**：已有 `?scene=` 预设，可以照"同一起点、改一个变量"做成对比录屏（同一片林子：晴天点火 vs 雨后点火），用于周五分享 / 对外短视频。
7. 酸、季节、地下水洞：工作量大，放后面。

不搬的：他的桌面挂件定位、他的方块美术和画面。

## 截图拆解：他的岩浆和水（用户 2026-11-17 提供 5 张小红书截图）

- 作者原话（意译）："除了水、岩浆、酸、瀑布和空中的灰与落叶，一切都是方块。"——**流体不做方块**，是贴着方块地形顺滑铺开的面。
- 岩浆：亮黄底 + 一块块暗橙结壳板 + 发光板缝；像素化纹理（和方块世界同一像素密度）；顺着台阶"顺滑地"淌下去。
- 冷却：深色石块，裂缝里透橙红；入海会长出一根根石柱，岩浆顺柱子往下流，旁边白汽。
- 水：透明青绿，浅处透出水底方块，深处偏蓝；岸边一圈白沫；剖面玻璃上能看到水体分层。
- 已做（2026-11-17）：岩浆 / 地表水流体面、结壳板 + 发光缝、岩浆石余热裂缝、越冷越稠。我们的差异：眼镜里黑 = 透明，所以"黑石头"用深灰、靠发光裂缝显形。
