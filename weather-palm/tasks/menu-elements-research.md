# 道具菜单重做：调研 + 方案（2026-11-19，v2 已定，按第 6 节分步实现）

用户反馈：菜单里很多道具不好用，闪电、萤火虫可以删。要的是**能和别的元素交互、改变场景的东西**，元素之间要有机制，再加动物（羊 / 兔子）。

## 1. 现在菜单里每一样的问题

| 道具 | 现在做什么 | 问题 | 建议 |
|---|---|---|---|
| 水 | 落地变地表水，流、积、渗；冲沙、灭火、冷岩浆 | 好用，是核心 | 留 |
| 沙 | 堆成方块堆，泡水变土，被岩浆烧成玻璃 | 好用 | 留 |
| 岩浆 | 流、冷成石、烧林、遇水冒汽 | 好用，最有戏 | 留 |
| 树种 | 落地变苗，有水有光长成树 | 好用 | 留 |
| 雪 | 手下一朵雪云，积雪、结冰、堆雪人 | 和"下雨"重复一半 | 留，但要和别的东西多点反应 |
| 花种 | 那一片草长起来 | 只是变绿，没后续 | 并进"蜜蜂"那条链（见下） |
| 食物 | 浆果，附近动物过来吃 | 动物少时看不到效果 | 改成喂羊 / 兔子的饲料，或删 |
| 鱼苗 | 只有放进水里才算数 | 几乎看不见 | 留给苍鹭吃（已有），优先级低 |
| 雾霾 | 挡阳光、伤植物，风吹散雨洗掉 | 负面道具，没人想放 | 删或改 |
| 旋风 | 乱走一阵，吹散雾霾、推云 | 和"手横扫刮风"重复 | 删或改成会卷走沙 / 羊的 |
| **闪电** | 劈一下 | 握拳再张开就是打雷，**重复** | **删** |
| **萤火虫** | 飞来飞去发光 | 纯点缀，不影响任何东西 | **删** |

## 2. 同类游戏怎么做"元素之间有机制"

- **塞尔达 旷野之息 / 王国之泪的"化学引擎"**（GDC 2017）：分"元素"（火、水、冰、风、电）和"材质"（木、石、金属、草、角色）。只有两条总规则：①元素改变材质的状态（火烧木头）②元素改变彼此的状态（水灭火）。规则少、组合多，玩家自己想出解法。**借：我们也只定少数几条通用规则，再让每个新东西挂上去。**
- **From Dust**（Éric Chahi）：水冷岩浆成石、岩浆和火烧植物；关键是**会自己行动的植物**——火树隔一阵自燃、点着周围；水树吸地下水，碰到热就爆出一大片水；爆炸树是唯一能改岩石的工具。评测说这些植物经常帮倒忙（放水树救火结果淹了村子）。**借："种下去之后自己按规则行动"的东西，比一次性道具有意思得多。**
- **Terra Nil**：链条式改造——风车给电 → 除毒器把废土变土 → 灌溉器把土变草 → 后面才解锁各生态；每一步都要前一步的地。**借：把"荒岛 → 绿岛"做成一条看得见的链。**
- **Reus**：相邻的资源互相加成（"共生"），动植物能升级成更高级的。评测吐槽加成规则"有点随意"。**借：相邻加成要符合常识（羊粪肥草、蜜蜂授粉），别做成随意的数值。**
- 我们自己已有的 `tasks/terraglass-ideas.md`：Terraglass 最出圈的是**动物的涌现行为**（兔子不走直线、踩出小路、气味）。

## 3. 一套通用规则（照化学引擎的思路，只定这几条）

每格已有的量：水、湿度、草、沙、土、石、岩浆热、火、雪 / 冰。新东西只按这几条和世界交互：

1. **热**：岩浆、火让周围变热 → 雪化、冰化成水、水冒汽、草木着火、动物逃。
2. **湿**：水、雨、雪化让地变湿 → 灭火、沙变土、草长、动物躲雨。
3. **吃 / 长**：草被吃掉会变秃，有粪 / 有水有光会长回来；吃光了 → 土裸露 → 风吹成沙（**过度放牧变荒漠**）。
4. **怕**：打雷、火、岩浆、旋风让动物逃；逃跑会踩坏花和苗。

## 4. 用户批注（2026-11-19）→ 方案 v2

> 生物要统一逻辑，只是形态不同（牛、羊……），都是一个逻辑。
> 至少要能：用岩浆破坏场景后，通过元素重建成树林 / 恢复自然。
> 可以堆土（不是沙子）把四周围起来，中间加水变成池塘，或者整个场景都是水。水底会自然长植物，然后可以加鱼。

这三条是验收主线，下面按它们重排。

### 4.1 一套生物逻辑，形态只是数据

现在 `sim.js` 已经有 8 种野生动物共用一套 `SPECIES` 表 + 一个行为循环，但它们**只会按绿化度自己出现，不能放**。改成：

- **一个 `Creature` 行为**（纯数据、Node 可测），每只都按同一组需求和反应活：
  - **栖息地**：陆地 / 水里（鱼就是"栖息地 = 水"的同一套逻辑）。
  - **吃**：吃它那一类食物（草 / 花和苗 / 水草 / 浆果）→ 那格的量减少；吃饱了长大、够多会生崽；没得吃会瘦、走远去找、最后离开。
  - **留下**：粪 / 排泄让那格长得快（草地、水草都是），和"吃"互相抵：少了地越来越好，多了越吃越秃。
  - **怕**：热（岩浆、火）、打雷、旋风 → 逃；下雨 → 躲到树下 / 洞里；水太深 → 绕开（陆地的），水干了 → 搁浅（鱼）。
- **物种只是一行数据**：模型 + 体型 + 吃什么 + 速度 + 群居多少只 + 繁殖快慢。第一批：**羊、牛、兔子、鱼**；原有鹿、狐狸、熊等也挪进这张表（行为统一后它们也能放）。
- 菜单里只放一格"**动物**"，再点一下换形态（羊 / 牛 / 兔子 / 鱼），或直接每种一格——**请你定**。

### 4.2 破坏 → 重建的一条链（验收：岩浆烧光一片后，能用道具救回成树林）

现在已有：岩浆冷成石 → 石被水泡会风化成土（很慢）→ 土湿 + 太阳 → 长草 → 树种长成树；烧过的地 `burnt` 慢慢长回。缺的是**玩家能主动推进每一步**，而且每一步看得见：

| 场景状态 | 用什么 | 变成 | 现在 |
|---|---|---|---|
| 烫岩浆 | 水 / 下雨 / 雪 | 冒汽，冷成石头 | 有 |
| 冷石头 | 下雨、倒水泡着 | 风化成土（**加快到几十秒能看到**） | 有，太慢 |
| 冷石头 | **堆土**直接盖上 | 土地 | 新（堆土道具） |
| 焦土 / 裸土 | 水 + 太阳 | 长草 | 有 |
| 草地 | 树种 / 花种 | 苗 → 树林、花地 | 有 |
| 草地 | 放羊 / 牛 | 粪让草更快变茂盛（羊少时） | 新 |
| 树林 | 蘑菇、鸟、鹿自己回来 | "恢复自然"的标志 | 部分有 |

加一个看得见的反馈：每恢复一片，地上一圈绿色的光扫过去（和现在的"需求"光圈同一套），状态栏显示"恢复 xx%"。自测：倒岩浆烧一片 → 按顺序用 水 → 土 → 树种 → 羊 → 若干秒后这片绿化度回到烧之前的 80% 以上。

### 4.3 堆土围池塘，加水成湖，水底长草，放鱼

- **土（新道具，替换沙子的位置或两者都留——请你定）**：像沙子一样一块块掉下来、按方块码，但**站得住**（坡度比沙陡得多，现在 `SOIL_REPOSE` 已经比沙子陡）、**不透水**、**不被水冲走**（压实的土墙）。沙子泡水才变土、会被水冲，所以围堰要用土。
- **池塘**：现有地表水本来就按高差流、积在洼地里——围一圈土，中间倒水就会积成池塘；水位到墙顶会从最低的口子漫出去（顺带一个玩法：在墙上留个口子放水）。
- **整个场景都是水**：沿岛边围一圈土墙，就能一直灌到整座岛变成湖（只剩高处露出来）。需要把"倒水"的量调大，或加"一直倒"的泉眼（备选），不然灌满太慢。
- **水底自己长植物**：水够深、待够久的格子长**水草**（一丛丛绿的交叉面片，随水晃），浅水边长芦苇 / 荷叶。水干了水草枯掉。
- **鱼**：就是 4.1 里栖息地 = 水的生物。放进有水草的池塘会游、吃水草、繁殖；水太浅 / 被岩浆烫会死、冒白；没水草会饿。苍鹭（已有）会来水边抓鱼。

### 4.4 其余

- 冰块、蜜蜂放第二批。
- 删：闪电、萤火虫（握拳已能打雷）。雾霾、旋风、食物要不要留，**请你定**。

## 5. 菜单 v2（已定，2026-11-19）

- 动物只占**一格**，放下去**随机生成**一种（落在水里就是鱼，落在陆地上随机羊 / 牛 / 兔子……）。
- 土、沙都留。
- 留食物、旋风；删闪电、萤火虫、雾霾、鱼苗（鱼并进"动物"）。
- 菜单：下雨、水、土、沙、岩浆、雪、树种、花种、动物、食物、旋风（11 格，5×3 放得下）。
