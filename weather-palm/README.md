# 掌心气象台 · Weather in Your Palm

桌上一座直径 34 cm 的野外体素小岛：雪山、岩壁、山坡上的云杉林和阔叶林、山泉流成溪、跌成瀑布汇进湖；
草甸、花海、湿地里住着兔子、鹿、狐狸，湖里有鱼、野鸭、睡莲，雨后水边冒出青蛙，夜里萤火和发光蘑菇。没有人。
你是巨人，手就是天气——下雨、放晴、刮风、打雷、投下手影；还能从**左手道具菜单**里挑东西往岛上放：水、食物、雪、雾霾、旋风、岩浆、闪电、沙、种子、花种、鱼苗、萤火虫。

画风是方块世界（"我的世界"一类体素游戏的路子；贴图、模型全部在代码里程序生成，不用任何现成素材）：
一个方块 1.6 mm（岛直径约 210 块，照像素村落西沟的密度）、每面 4×4 个贴图像素（贴图像素 0.4 mm，再细眼镜里会闪）；地形是一格一根的方块柱（草方块顶面 + 侧面挂草皮、往下是泥土再往下是石头，雪只落在方块顶上）；
北半边一道两级的红石崖（崖腰一溜平台、崖顶台地长林子，崖面是一层层微微起伏的岩层，低处红砂岩、高处灰岩），三条溪在崖上切出豁口跌下来；山坡切成一级级台地；
树按方块搭，树冠是几团拼起来、上亮下暗的两色（橡树、白桦、云杉、油松、侧柏、灌木、两格粗的大橡树，几片坡上成片的秋色黄栌和黄叶树），林子里有倒木、树桩；草、花、蕨、芦苇、蘑菇是交叉面片；云是一格一格的平板方块；
溪往下跌一格的地方立着竖的流水面。光照是方块游戏的固定面明暗（顶 1.0、南北 0.8、东西 0.62）加方块角落的环境光遮蔽，
不用卡通分档、不描边、不泛光；颜色自然偏灰，草的颜色随湿度、生长度变（缺水发黄、长不好露出泥土）。
特效和界面也按同一套：所有光都是方形、分三档变淡（太阳、月亮是方的），手势提示是地上一格一格对齐的方形选框，请求气泡是物品格样式，面板和按钮是中性的石灰色斜面；夜里的光只来自发光蘑菇（淡青）。
单个 `index.html` + three.js r160（CDN importmap），零构建。

## 上帝模拟：开局是荒岛

开局整座岛是荒的：东边沙丘（风纹）、西边和崖下红黏土（龟裂）、山坡碎石、湖边干泥滩，只有山泉还在流，没有草、树、动物。
岛不会自己活过来（不操作 200 秒还是荒的），要靠你：下雨把地浇湿 → 有水有光的地方先冒草和野花 → 每棵树有自己的门槛，那片地长得够好它才冒出来，
从小苗、半大长到成树 → 岛绿到一定程度动物自己来（绿度 0.3 兔子、0.45 鹿、0.6 狐狸），睡莲、野鸭也跟着出现。
土质决定长得快慢（`sim.js` 的 `SOIL_GROW`：泥滩 1.15、褐土 1、红土 0.8、碎石 0.55、沙丘 0.45），也决定长什么树：
沙丘上仙人掌（有的开花）、金合欢；水边柳树、棕榈；红土上金合欢、紫花楹、侧柏；褐土上橡树、白桦、成片的秋色（黄栌、黄叶、锈橙、山桃）；半山云杉、蓝云杉、油松、侧柏。
测试和场景预设仍用原来的"野岛"开局（`createWorld(seed)`；荒岛是 `createWorld(seed, { start: 'barren' })`），场景 `barren` / `bloom` 看荒岛和浇了一半的样子。存档升到 v3。

## 特效（参考 Terraglass 的截图借鉴手法，没用它的素材）

- **去噪 + 体素 AO**：地形和物件都是一块一个颜色（块间只有 3–8% 的色差），不在块里画像素噪点——形体交给光影；树、动物、石头的体素在建模时烘焙了四角 AO（方块游戏的"两个侧邻 + 一个角邻"规则，写进顶点色，运行时零开销），地形的角落 AO 改成平滑过渡。
- **收调色板**：草和树叶统一成偏灰的橄榄 / 鼠尾草绿；岩层只用红砂、奶黄、浅赭一族暖色；秋色、花树只在少数几片坡上成小片；受光暖、背光冷紫，崖面按太阳方向分明暗（斜阳时最明显）。
- **发光焦点**：碎石坡、崖上 16 簇水晶（青白、底部淡紫，不受光照，荒岛上也有），白天偶尔闪星芒，夜里自己发光并照亮周围一圈；夜里林子里有萤火，岛越绿越多；灯光从 8 盏扩到 16 盏（蘑菇 + 水晶）。眼镜里叠加显示本身就是"泛光"，发光的东西在透视里最好看。
- **桌面后处理**（只在桌面预览 / 截图，眼镜不走）：泛光加强（只对亮的东西：岩浆、水晶、萤火、雪顶）、暗部偏冷亮部偏暖的调色、暗角。
- **树（向 Terraglass 靠）**：阔叶树是盆景式——主干分两三根斜枝，枝头一片片扁平的云团，云团间看得见枝；云杉是一层层枝盘、梢下垂、层间露干；
  树冠三色：顶上露天的亮、偏暖黄，底下悬空的暗、偏冷，背光侧再暗一档；叶色比之前深一档。阔叶树更大、间距更大（棵数少、每棵更有型）。
- **水（向 Terraglass 靠）**：清的水体——浅处青绿透底、越深越蓝越不透明；平滑的小波浪法线（0.4 mm 格取样）、斜看反射天光（菲涅尔）、太阳高光；
  湖边一圈白浪、溪边只零星几点；瀑布面是一道道往下冲的蓝白条。
- **手**：和其他项目（星轨对决）同一种半透明手——WebXR Input Profiles 的 generic-hand 模型（MIT，`assets/hands/`）+ 菲涅尔蓝边（白底、边缘 (0.5, 0.72, 1)、不透明度 0.35，照 VITURE SDK 的 M_VitureHands）；
  不靠 XRHand，直接用 25 个关节（岛坐标）摆骨头，所以鼠标的手、教学示范手都是它。眼镜里看得见真手，不画。
- **倒的流（像瀑布）**：水、岩浆、沙不再是直直一串方块——从指尖顺着手指方向冲出去、划一道弧落下（越高冲得越远，落点就是东西真正落的地方），越往下越宽、左右微摆，
  带子上一道道亮暗条纹往下流；水是浅蓝带白条、边上断续像水帘，落地溅白水珠；岩浆是金黄芯橙红边、零星结块，落地溅火星、一团光；沙是一粒粒的细流。
- **岩浆烧植被（真实反应）**：能烧多少按那片地实际长了多少（荒地上的岩浆点不着东西）；烫的岩浆把 3 格内的草木烤干（越近越快，土壤湿度跟着降、草发黄），
  烤干了就着，紧挨着的很快着；火顺风蔓延、雨浇灭；烧过的树是灰褐的枯树、矮一截。湿的林子不会马上着，要先被烤干。
- **多彩分区**：东边是红石峡谷（照美国西南 / 新疆的红砂岩：平顶台地被东溪切出两级峡谷，台地外的荒漠上立着三座方山、三根石柱；崖壁深红、橙、奶白、锈红、橙粉一层层；台地上是干黄的荒漠草、仙人掌、金合欢、杜松）；
  西坡枫林（红、橙）、南湖边樱花林（粉，地上落满花瓣）、中间银杏（金黄，地上金叶）、北边台地针叶林、其余是杂树。分区在 `sim.js` 的 `biomeAt` / `inCanyon`。
  新树种：樱花（深褐干、平展的粉色云团）、银杏（直干、往上收窄的金色树冠）；枫叶颜色更艳。非绿色的树高光偏白（不偏黄绿）。
- **不挡画面的标记**：岛上的"需要"不再悬一个方框——地上一圈光点圈出需要的地方（完成多少就点亮多少颗，颜色按天气），上面离地 1.5 cm 浮一个小图标（无框、半透明）；
  完成 / 新动物的弹出图标也小一号、低一点；太阳、月亮改成圆的柔光（不再是大方块）。场景 `request` 看效果。
- **动物（照像素村落的做法）**：`animals.js` 里每种一张侧视像素画，按到轮廓的距离"充气"成体素（中间鼓、边上薄，带四角 AO）；两帧走路 + 一帧低头（吃草 / 喝水 / 啄食），睡觉侧躺。
  八种：野兔、梅花鹿（白点、鹿角）、赤狐（白尖尾巴）、松鼠、野猪、苍鹭（湖边）、岩羊（峡谷）、棕熊（针叶林）。比例照真实体型（松鼠 < 兔 < 狐 < 野猪 ≈ 岩羊 < 鹿 ≈ 苍鹭 < 熊），整体比树小得多；
  荒岛上按绿度一种种来，各有自己的地盘和繁殖上限（`sim.js` 的 `SPECIES`）。场景 `zoo` 排成一排看模型。
- **风雨火都改变场景**：风把枫叶、樱花瓣、银杏叶吹落，顺风打旋落地、在地上躺一阵；干地和沙地扬尘；沙堆顺风挪（`matter.js`）；湖上顺风起浪、风大起白头；
  林火在大风里飞火星，在下风 2–4 格外点着新的火头；着火的树树冠上窜火苗冒烟。下雨湿沙塌下来。场景 `gale` / `wildfire`。
- **云**：积云——平底、圆鼓鼓的顶、顶上鼓出几团，越高越亮、底下偏灰蓝。**水**：天光反射、高光、焦散都收了，池塘不再一片白（白点只在下雨时有）。
- **太阳投影**：地形 + 树冠拼成高度图，沿太阳方向往回找"高过多少才照得到"（CPU 每秒最多算一次，存 8 位纹理），所有方块材质在 `applyShade` 里按高度比较：
  受光面微暖、背光冷紫（不压黑），阴天、雷雨、夜里自动减弱。早晚斜阳的长影子看场景 `dusk`。
- **岩浆**：浮着的结壳石板 + 发亮的缝（细胞噪声），热的地方是金黄熔芯，越凉石板越大、缝越细；岩浆的光模糊后照到周围地形、树上（橙色）；冒火星和淡紫灰的烟。
- **水**：岸边一圈一涌一涌的白浪、浅水底的焦散光纹、瀑布上的白水。
- **云**：顶上一层亮、底下偏灰蓝；早晚顶上染粉橙。
- **岛的剖面**：外沿侧面一层层红土、砂砾、地下水层（蓝）、岩浆脉（发光的橙）、基岩，零星金、铜矿点。

## 怎么玩

| 手势（头显里） | 效果 | 电脑 |
|---|---|---|
| 手掌朝下悬在岛上，停一下 | 下雨：手下聚云，停得越久雨越大，手慢慢移云跟着走 | 选"雨"，左键按住 |
| 掌心朝上摊开 | 放晴：附近的云散开、升温 | 右键按住 |
| 手立起来横着扫 | 刮风：推云、吹弯草木、蒲公英种子飞开 | 左键按住快拖 |
| 握拳蓄力 0.6 秒再张开 | 打雷：劈在手下最高的山尖或大树上，动物四散 | Shift + 左键按住再松开（或空格） |
| 左手掌心朝向自己、张开 | 弹出**道具菜单**（4×3 物品格），右手食指尖点一格停 0.3 秒或捏一下 = 选中；左手放下菜单收起 | 底部按钮，`[` / `]` 轮换 |
| 右手立起来、指尖朝下停住 | **放**选中的道具：落点在指尖下方 | 选好道具，左键按住 |
| 手挡在太阳和岛之间 | 手影：遮阴降温、蒸发变慢 | 鼠标指到哪，"手"就在哪 |
| 双手捏住 1.2 秒 / 单手捏住岛边拖 | 重新摆到眼前 / 挪岛 | XR 里 R 键 |
| 手掌平放在岛外的桌面上 1.2 秒 | 把岛落到桌面高度 | PageUp / PageDown |

**道具**（每一样都改变岛的状态，`test/tools.test.mjs` 逐个测）：

| 道具 | 对岛的影响 |
|---|---|
| 水 | 浇湿土地、化雪、洗掉雾霾、抬高湖面；浇在火上灭火，浇在岩浆上冷成石头冒白汽 |
| 食物 | 落在最近能走的地上；附近的动物过来吃，吃饱的会生小的（兔 ≤14、鹿 ≤7、狐 ≤4）；放久了烂掉 |
| 雪 | 手下聚一朵雪云：地上积雪（盖住草、树变白）、气温降、湖面结冰；太阳出来化成水把地浸湿 |
| 雾霾 | 灰黄的霾挡太阳，植物长得慢、动物躲开；风和旋风吹散、雨洗掉 |
| 旋风 | 一股小龙卷在岛上游走（最多 3 股），吹散雾霾、推云，过一阵自己消失 |
| 岩浆 / 沙 / 种子 | 见下 |
| 闪电 | 直接劈下去，干的林子会着火，湿的不会 |
| 花种 | 那一片草一下子长起来、开出新花 |
| 鱼苗 | 放进湖里鱼变多；放在地上只会扑腾一下 |
| 萤火虫 | 放出一群，绕着落点飞，夜里最明显 |

**倒进来的东西**（`matter.js`，96×96 格，每格约 3.5 mm）：
- 岩浆往低处流，越烫越稀；慢慢结成深紫灰的石皮，裂缝里还透红；下雨冷得快、冒白汽；流进溪和湖"嗤"地变石头，堆够了能填出新陆地；烫的岩浆点着干的草木。
- 火在林子、草地里蔓延，顺风更快，湿的点不着，下雨就灭；烧过的地方变灰，过一阵再长回来。
- 沙子堆起来，陡了往下滑（有休止角）；倒进水里能填出浅滩。
- 种子落在草地上变成小苗，有水有光就长成嫩绿的树，慢慢变深。

识别到手势时手下地面先亮一圈，约 0.3 秒后才生效，认错了把手放松就取消。
岛上会冒出"需要"的气泡（🌧 草甸要雨、☀️ 花要太阳、🌬️ 蒲公英要风、⚡ 山林要场雷雨、🖐️ 兔子要阴凉），第一次出现某种时浮出一只示范手；
每完成两个"需要"岛升一级（共 8 级），新的动物从林子边走出来；满级的夜里漫天萤火。没有失败。

动物的行为（`sim.js`）：吃草时低头、溜达；下雨兔子钻洞、鹿躲进林子；打雷四散逃开；手低低地靠近时鹿抬头看你，兔子太近就跑；
彩虹出来兔子蹦；口渴了去水边喝水；夜里兔子、鹿睡觉，狐狸出来转；不走进水、岩壁、岩浆和火里。

其他键：1–7 选前七个工具，`[` / `]` 轮换道具，M 静音，T 时间 ×4。

## 真机还没验证的

- **手势阈值**按合成手标定（`gesture.js` 的 `CFG`），"倒"是新加的姿势（立掌、指尖朝下），最需要在眼镜上试；第一次戴先开 `?debug=1` 看特征值。
- 光学透视下的亮度（岩浆冷却后的石头、夜里的林子偏暗）、手的深度遮挡。

## 渲染上踩过的坑

- 雨丝在顶点着色器里按屏幕方向求垂线再归一化，在 ANGLE 下整条雨都不出现、也不报错；改成沿视图 x 加宽度。
- 网格缺法线时卡通光算出 NaN，桌面上的 bloom 会把整屏染黑。
- 单通道 `DataTexture` 宽度不是 4 的倍数要设 `unpackAlignment = 1`，否则错行上传，AO 和阴影落错位置。
- 半透明的水会盖掉水下的精灵（鱼），要贴着水面画。
- 岩浆流进溪里每格都会"嗤"一次，白汽要限量，不然连成一条白带。
- 气泡图标不用系统 emoji（彩色写实、各平台不一样，混在像素世界里很扎眼），用 `index.html` 里 `PIX` 的 16×16 字符画。
- 着色器里手写的颜色是 sRGB 值，参与光照前要 `pow(c, 2.2)` 转线性，否则整个画面发白发灰（`art.js` 的 `s2l`）；JS 里同理用 `setRGB(..., THREE.SRGBColorSpace)`。
- `vertexColors: true` 的材质用在没有 `color` 属性的几何（BoxGeometry）上会整块变黑：没有顶点色时要给 `color`。
- 用 Python 往 JS 字符串里写 `
` 时要转义，不然变成真换行，整页报语法错误。
