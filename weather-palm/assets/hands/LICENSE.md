# 手模型来源 · generic-hand

`left.glb` / `right.glb` 原样取自 WebXR Input Profiles 的 `@webxr-input-profiles/assets` 1.0.20
(`dist/profiles/generic-hand/`),下载地址:

- https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/left.glb
- https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/right.glb

项目主页:https://github.com/immersive-web/webxr-input-profiles 。游戏里加载后替换成自己的半透明菲涅尔材质(`js/xr-hand-visual.js`),模型文件本身未改动。
