# CINDER 09 · 废土配给站

第三场景根据圆筒废土概念图重建为可交互的实时几何场景。保留海港和生态区，按 A 海港 → B 生态 → C 废土循环；每次翻转仍为原地 180°，由隐藏的下一场景交替占用圆盘两侧。

## 2026-10-20 模型细化

- 居住楼新增不规则铆接板、外露斜撑、错缝屋面、通风格栅与屋顶检修设施。
- 新增回收装甲货车，包含轮胎胎块、轮毂、车头防撞架、侧装甲、外置排气和顶架。
- 机修棚增加屋面补片和门架；残楼增加落石、弯曲钢筋和不同材料的封板。
- 飞轮、锅炉和矿车增加紧固件、散热片、加强筋；地面增加废板、钢杆和碎石。
- 锈蚀纹理增加不规则氧化斑、金属划伤与旧漆磨损。
- 使用 `?scene=cinder` 可直接打开第三场景。所有模型继续在浏览器生成。
- CINDER 09 天气按钮显示“晴天 / 热风扬尘 / 沙尘暴 / 废土暴雨”，按钮在收起的工具栏中也可直接使用。沙尘暴提高扬尘和雾密度；暴雨启用密集斜雨、雷电、湿润材质与局部积水。
- 地面增加连续的起伏沙地、风蚀纹理、不同高度的沙丘、冲沟、轮迹与分段石板路。回收车移至南侧空地，避开建筑和围栏的视觉交叠。

本次验证：桌面近景、390 × 844 手机视口、停机 / 水泵 / 闸门按钮、C → A 翻面。实测连杆长 1.05，静态包络 9.477；未测试真实 XR 头显。本次未运行下文提及但当前检出中缺失的 `verify-three-scenes.mjs`。

## 动态约束

- 总动力暂停会冻结飞轮、活塞、货梯及矿车时间；水泵与闸门独立控制。
- 曲柄半径 0.24，连杆长度 1.05，滑块位置由滑块曲柄约束计算。
- 货梯高度在 1.02–2.55 之间连续变化，端点有停靠时段。
- 第三场景不渲染海面与积雪；暴雨仅在选择对应天气时出现。
- 材质、屏幕、铁皮纹理和建筑均由代码生成，不加载概念图作为背景。

## 验证

`verify-three-scenes.mjs` 检查 12 次连续翻转、场景顺序、模型回正、固定轴高、运输周期连续性和曲柄连杆长度。浏览器验收覆盖实际按钮、暂停、三场景往返、昼夜和圆筒包络；未进行真实头显硬件测试。
