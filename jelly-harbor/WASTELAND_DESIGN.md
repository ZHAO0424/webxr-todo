# CINDER 09 · 废土配给站

第三场景根据圆筒废土概念图重建为可交互的实时几何场景。保留海港和生态区，按 A 海港 → B 生态 → C 废土循环；每次翻转仍为原地 180°，由隐藏的下一场景交替占用圆盘两侧。

## 建筑与构件

| 分区 | 构件与材质 | 行为 |
|---|---|---|
| 蒸汽动力站 | 锈蚀锅炉、火箱栅格、烟囱、法兰、压力表、飞轮、曲柄、连杆、滑块、皮带发电机 | 飞轮与恒长连杆联动；炉火闪动、蒸汽排放、表针摆动；点击切换动力 |
| 破损混凝土楼 | 裸露梁柱、残墙、钢筋、回收铁皮封板、布棚与屋顶水罐 | 布棚轻微起伏 |
| 拼装居住楼 | 不同层数与错位楼板、外廊、窗栅、背面补丁、斜撑、检修梯、储水罐、热交换箱 | 暖色室内照明、静态电缆 |
| 弧顶机修棚 | 半圆回收金属屋面、独立外肋、卷帘门、外置罐和烟管 | 棚布轻微起伏 |
| 数据修复铺 | 发光计算机、裸露机架、工作台、回收电缆 | 保留数字技术与原始动力并存的世界设定 |
| 配给水井 | 低水位、露出的池壁、水罐、手动泵和管线 | 独立抽水开关、泵柄往复、可见出水 |
| 货运绞盘 | 四柱支架、斜撑、升降平台、货箱、绳索、卷筒、上层连廊 | 24 秒往返周期，停靠后提升，绳索长度随平台更新 |
| 轨道矿车 | 固定轨距弯轨、枕木、轮轴、锈蚀料斗与煤块 | 与总动力同步，沿轨道停靠往返 |
| 防御入口 | 拼接围墙、盘绕铁丝、补强斜撑、双岗亭、棚布、配给标牌 | 闸门独立升降 |
| 聚落地面 | 沙地、局部风积沙、散落砖石、木板路、配给摊位、居民剪影 | 局部浮尘 |

## 动态约束

- 总动力暂停会冻结飞轮、活塞、货梯及矿车时间；水泵与闸门独立控制。
- 曲柄半径 0.24，连杆长度 1.05，滑块位置由滑块曲柄约束计算。
- 货梯高度在 1.02–2.55 之间连续变化，端点有停靠时段。
- 第三场景不渲染海面，雷暴与积雪不覆盖沙漠场景。
- 材质、屏幕、铁皮纹理和建筑均由代码生成，不加载概念图作为背景。

## 验证

`verify-three-scenes.mjs` 检查 12 次连续翻转、场景顺序、模型回正、固定轴高、运输周期连续性和曲柄连杆长度。浏览器验收覆盖实际按钮、暂停、三场景往返、昼夜和圆筒包络；未进行真实头显硬件测试。
