# 双面圆筒沙盘 · WebXR

[打开演示](https://zhao0424.github.io/webxr-todo/jelly-harbor/)

Three.js r160 单页场景：工业港口与生态研究园区共用一个原地翻转的圆筒装置。

- 港口：货轮、集装箱机械臂、运输艇、探照灯与天气系统。
- 生态区：多层连廊、开合玻璃屋顶、等距双轨运输车、岸上至水下接收台的自动转运。
- 中央景观池使用独立的小幅驻波与入水涟漪；生态区不受港口雷暴影响。
- 鼠标拖动环视、滚轮缩放，页面按钮切换圆盘、控制台和设备。支持可用设备上的 WebXR。

使用 HTTPS 或 localhost 打开。Three.js 和附加模块通过 CDN 加载，需要联网；其余几何、材质与纹理由代码生成。
