# 果冻港口（NEXUS / 2086）· XR 左手菜单 · Research + Plan

> 状态：**已实现（2026-11-13），未上真机**。用户批注：三个待定项全部按推荐（保留"点设施看说明"、掌心朝向自己才出现、右手先只用射线）。
> 代码在 `index.html` 的 `xrMenu` 模块。已验证：三面菜单贴图中英文都放得下；菜单按钮能触发对应功能；射线打到菜单能认出对应按钮；翻面预编没有退化；控制台零报错。
> 还没验证：左手翻掌出现 / 消失、右手射线指向是否顺手、字够不够清楚、底板在眼镜里的亮度（黑等于透明）。

需求原话：进眼镜后，所有按钮都集成在左手的菜单栏，不要放在场景模型里；菜单栏设计和内容风格一致。

## 1. Research：现在 XR 里有哪些"按钮"

| 位置 | 内容 | 现在在 XR 里 | 代码 |
|---|---|---|---|
| 圆盘前方浮空的 3 块板 | 翻转圆盘 / 昼·夜 / 切换天气 | 射线 + 扳机/捏合点 | `textPanel()` + `xrButtons`，`index.html` 约 1114 行，挂在 `world` 下，进 XR 才显示 |
| B 面 EDEN 场景里 | WATER / CANOPY / NURSERY 三个控制台，温室、探针、气象桅、收割龙门、穿梭车 | 射线点模型本身就触发（养护 / 玻璃罩 / 循环水） | `ecoControl()`、`ecoAction()`，约 546–769 行 |
| C 面 CINDER 场景里 | 发动机、水泵、货梯、矿车、闸门 | 射线点模型触发（动力 / 水泵 / 闸门） | `wa()`，约 888–1001 行 |
| 所有面 | 点设施看说明（`showInfo` → 网页右上 `#info`） | **眼镜里看不到**：说明只写在网页 DOM 上 | `selectRay()` 约 1152 行 |
| 网页 | B 面 `#ecoTools`、C 面 `#wasteTools` 各一排 3 个按钮 | XR 里不存在 | 约 1124、1147 行 |

输入现状：
- `VRButton.createButton(renderer)` 没有请求 `hand-tracking`，眼镜里只有手柄/系统射线（`getController`），**拿不到左手关节**，所以现在做不了"挂在左手上"。需要改成请求 `hand-tracking`（入画用的就是这个，本机 VITURE OpenXR 已验证双手追踪）。
- 进 XR 时 `world` 缩到 0.12，人站在 `rig (0,0,2.8)`。
- 两只手的射线都会触发 `selectRay`，打到什么算什么。

三面的视觉风格（网页截图实测）：

| 面 | 气质 | 网页上的颜色 |
|---|---|---|
| A 重型货运 SECTOR 07 | 冷灰钢、黑色工业 | 面板 `#142025`（约 75% 不透明）、细边 `#60716b`、字 `#bfc8c0`；主按钮「翻转圆盘」砂色 `#a8a28a` + 深字 |
| B 生态修复 EDEN 12 | 浅色玻璃、青绿 | 设施按钮浅底 `#e4ede8`、边 `#adbfba`、深青字 `#213e42` |
| C 废土配给站 CINDER 09 | 锈铁、黄铜 | 设施按钮 `#403225`、边 `#8e7752`、字 `#decaa7` |

共同点：小圆角（2–8px）、细描边、Arial / 微软雅黑、英文眉题大字距（如 `SIDE B / 02`、`LIVING SYSTEMS`）。

## 2. Plan

### 2.1 菜单挂在哪、怎么出现
- **挂在左手腕**，菜单面朝向你、在手背上方约 6 cm。**左手掌心朝向自己时出现**，翻回去就淡出（有回差，不会抖着闪）。
- **没有手部追踪、只有手柄时**：挂在左手柄上，一直显示。
- **左手完全没追踪到时**：菜单停在视野左下角，跟着视线慢慢跟随，保证任何时候都能找到。
- 菜单出现时，左手的射线和捏合不再触发场景，避免"举起左手看菜单时误点"。

### 2.2 怎么操作
- **右手射线指着菜单上的按钮 → 捏合 / 扳机**。沿用现在的选择逻辑，只把命中目标从场景换成菜单。
- 射线指到哪个按钮，那个按钮就加亮描边（hover）；按下时有一下缩放 + 音效（没有音效就只做缩放）。
- （可选）右手食指直接戳菜单按钮。默认先不做，等真机看射线够不够顺手。

### 2.3 菜单内容（随当前面自动切换）

```
┌──────────────────────────────────────┐
│ SIDE B / 02 · LIVING SYSTEMS          │  ← 眉题：面编号 + 徽标，和网页左上一致
│ 生态修复 · EDEN 12                    │
├──────────────────────────────────────┤
│ [ ↻ 翻转圆盘 ]                        │  ← 主按钮，砂色
│ [ ☀ 昼 / 夜 ]   [ ☂ 晴天 ]            │  ← 天气按钮直接显示当前天气名
├──────────────────────────────────────┤
│ [ 暂停养护 ] [ 打开玻璃罩 ] [ 关闭循环水 ] │  ← 只有 B 面有；C 面换成 停机检修 / 停止抽水 / 升起闸门；A 面没有这一行
├──────────────────────────────────────┤
│ 说明：玻璃温室 · 养护运行 / 玻璃罩展开…   │  ← 最近一次点的设施说明（见 2.4）
└──────────────────────────────────────┘
```
- 按钮文字和网页共用同一套中英文案（`ecoRun` / `wasteRun` 等），切换语言时菜单一起重画。
- 翻面过程中，翻面键显示「圆盘翻转中…」并变灰，和网页一致。

### 2.4 场景模型
- **XR 里删掉圆盘前那 3 块浮空板**。
- **XR 里，场景模型不再当按钮用**：点控制台、发动机、闸门等不再触发动作，这些动作全部只在菜单里。WATER / CANOPY / NURSERY 控制台的模型本身保留，它们是场景的一部分。
- 网页（非 XR）完全不变：网页上点模型照样能操作。

### 2.5 视觉风格
- 一整块画布贴图（一次绘制），按钮是贴图上的区域，用射线命中位置换算 UV 来判断按的是哪个按钮。
- 底板沿用网页面板：深色半透明 `#142025`、细边、小圆角。三面共用一套骨架，**强调色随面切换**：
  - A 面：按钮钢灰底 + 砂色主按钮。
  - B 面：设施按钮用浅玻璃色 `#e4ede8` 底、深青字。
  - C 面：设施按钮用锈色 `#403225` 底、黄铜边 `#8e7752`、米色字。
- 眼镜里黑等于透明，所以底板不能纯黑。底板透明度和亮度会在真机上再调，保证叠在场景上字还清楚。
- 尺寸：菜单宽约 16 cm，中文字号按 1 m 外约 ≥ 1.2 cm 的视角折算（真机再标定）。

### 2.6 不改的
- 翻转、昼夜、天气、养护等的逻辑本身一概不动，菜单只是调用现有函数。
- 网页界面、桌面交互不变。

## 3. 验收

1. 无头浏览器渲染三面的菜单贴图截图，人工看风格是否和网页一致、字是否放得下（中英各一遍）。
2. 模拟输入：用脚本把"右手射线"对准菜单每个按钮，确认触发的就是对应功能，场景模型在 XR 下点了没反应。
3. 现有翻面预编（`warmFlipPrograms`）照样生效，菜单不引入新的翻面卡顿（复用之前的测量脚本）。
4. **真机**（需要你戴眼镜）：左手翻掌出现/消失是否自然、右手射线点按钮是否准、字是否清楚。
