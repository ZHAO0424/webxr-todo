# 粒子场 · Particle Fields · WebXR

伸手进去，搅动一团悬浮的粒子。手停下后它继续旋，慢慢停。

**▶ [打开](https://zhao0424.github.io/webxr-todo/particle-fields/)** — 电脑上用鼠标，头显里用手。界面中英双语。

零依赖：一个 HTML 文件，原生 WebGL2 + WebXR Device API，没有任何框架或 CDN。

## 三种形态

**渐变** — 八章轮流接管同一团粒子：前六章是数学，每章 16 秒、交接 6 秒；第六章停满后直接切到 Ⅶ 黑洞、Ⅷ 极光（各停 22 秒，整套换形态，不做混合），再回到 Ⅰ。桌面 ←/→ 或 1–8 换章。界面中英双语，跟浏览器语言，右下角按钮可切换。
换的是力的来源，不是参数；交接时两章的力按权重叠加，粒子自己流过去。

| 章 | 数学 | 粒子系统里的写法 | 颜色从哪来 |
|---|---|---|---|
| Ⅰ 旋度噪声 | v = ∇×ψ，∇·v = 0（Bridson 2007） | 速度场 | 等离子冷蓝→紫 |
| Ⅱ 洛伦兹吸引子 | ẋ=σ(y−x) ẏ=x(ρ−z)−y ż=xy−βz（1963） | 速度场 | 粒子在哪只翅膀上 |
| Ⅲ 霍普夫纤维化 | 球极投影下 v = (2(xz−y), 2(yz+x), 1−x²−y²+z²)/2 | 速度场 + 牛顿步贴到三层环面 | 纤维在 S² 上的底点 arg(z₁z̄₂) |
| Ⅳ 叶序 | θₙ = n·α，yₙ = 1−2n/N（Vogel 1979 的球面版） | 每粒一个目标点 | 南北金色渐变 |
| Ⅴ 克拉尼图形 | f = Pₗᵐ(cosθ)·cos mφ，沙落向 f = 0 | 牛顿步 −f∇f/\|∇f\|² + 按振幅抖动 | 沙的暖白 |
| Ⅵ 密度波 | 中心椭圆 b/a = 0.55，朝向随半长轴转 3.0 rad（Kalnajs 1973） | 每粒一个目标点 | 核球暖黄→外盘蓝白 |

同一只手在不同章里是不同的东西：混沌里一碰，挨着的两粒就分道扬镳；秩序里搅乱之后会自己回来。

几个调出来的结论：
- **克拉尼用牛顿步，不用 −∇(f²)。** Pₗᵐ 的幅度随 m 差几个数量级，梯度下降每个振型都得单独调力度；
  −f∇f/|∇f|² 直接就是到最近节线的位移，和量纲无关。
- **叶序的图案不是单调的。** 黄金角是最难用分数逼近的数，点阵最匀、什么线都没有；离线撒点比过，
  偏 +0.0003 有细线、+0.0006 又变匀、+0.001（≈18/47）线最清楚。这一章让 α 从黄金角扫出去再回来。
  点必须小、拖尾必须短，否则几毫米的线间距会被填平。序号要以赤道为零点，否则 α 一变南极每秒转好几圈。
- **霍普夫只取 |z₁|² ≥ 0.55 的环面。** 更外层的环面内圈贴到轴上、外圈甩出球外，投影是一团乱麻。
- **星系的扁率决定有没有臂。** b/a = 0.72 时椭圆太圆，挤不出密度差；0.55 才是两条干净的臂。

**黑洞** — 吸积盘 + 开普勒微分自转（越靠内转越快）+ 事件视界（掉进去的粒子被吞掉，
从外缘重新流入）+ 多普勒集束 + 光子环 + 引力透镜的次级像 + 三个自由翻滚的环。
伸手可以把物质推进视界，也可以推着三个环往任意方向转。

**极光** — 三道帘子在黑里朝你流过来，伸手能把它搅开。配色照真实极光的发光高度
分层：洋红的帘脚（N₂ 第一正带）→ 氧的 557.7nm 绿 → 往上转蓝紫、越高越淡。帘面上有
沿磁力线的竖向射线，帘脚是锐利的亮边 + 往上拖的软尾，褶皱会沿着整条弧跑过去。
底下有一层倒影，和帘脚接在一起就凭空生出一条地平线。握拳 = 减速。

## 怎么做的

```
模拟层（浮点纹理 ping-pong + MRT，与视角无关，双眼只算一次）
  posTex   xyz 位置 + w 寿命
  velTex   xyz 速度
  histTex  环形缓冲 = 拖尾
渲染层
  粒子 → RGBA16F（纯加法，能量无上界）
       → 逐级降采样 1/4 → 1/8 → 1/16
       → 合成 1 - exp(-(scene + bloom) × exposure)
```

状态放在粒子里，不放在体素里——64³ 的体积对丝缕太糙，128³ 又扛不住立体 raymarching。

**用叉积，不是直接加速度。** 这一行决定了是「搅」还是「吹」：

```glsl
acc += cross(handVel, r) / (dot(r,r) + 0.0006) * falloff * strength;
```

叉积让粒子绕着手的运动轴转，手划过之后继续卷。直接加 `handVel` 是推开。

**速度场用旋度噪声。** 势场是 `p += sin(p.yzx * f) / f` 那套多倍频正弦置换（`.yzx` 那个
swizzle 是流体感的来源），取旋度后无散度，粒子不会堆积也不会凭空消失——省掉整个压力投影。

**水要贴在壁上，而且要慢。** 拿走廊速度当水速（11m/s）只是一片看不清的拉丝——快没有
信息量。现在粒子被约束到一个扁椭圆截面的薄膜上（所以水是"覆盖隧道"的，不是穿过空气飞），
顺流只有走廊速度的 22%，再加一点向下的重力让水往低处淌。结构呼啸而过、水缓缓流，层次
就是这个速度差。

**噪声的空间尺度决定"划痕"还是"脉络"。** 邻近的粒子只有落在同一个噪声特征里才会一起动。
频率高 = 一地细碎的独立划痕；降到四分之一 = 成股的纹路，那才像水面。

**拖尾长度不能跟着帧率变。** 尾巴长度 = 速度 × 槽数 × 两次写入的间隔。每帧写一次历史，
就意味着 240fps 下的尾巴只有 72Hz 下的三分之一——桌面上调好了，头显里就是另一个东西。
隧道模式改成固定 1/42s 写一次，尾巴长度和帧率解耦。

**雾是叙事工具。** 雾薄（0.024）意味着一百米外的东西也一样清楚，整条走廊一眼望穿。
提到 0.062 之后结构会一层一层从黑里显出来；而贯穿轨单独吃 ×0.30 的雾，所以它仍然能
一直延伸到灭点。暗的先没入黑、亮的继续往里走——纵深是这么来的。

**流线要画成带子，不是点。** 点精灵在 90Hz 的头显里会散成虚线 —— 11m/s ÷ 90 = 12cm 的
间距，而点只有几毫米。改成在相邻两个历史槽之间拉一条正对相机的带子，速度再快也是连续的。
带子必须按距离衰减：远处的流线在屏幕上全汇到灭点那一个点、密度暴涨，而线宽有像素下限
撑着不会变细，不衰减就会烧成一坨死白。

**循环在着色器里做。** 横档和流线按 `aWrap` 对 z 取模折回 —— 无限长、每帧零数据更新，
而且是在雾里出现，看不见弹出。只有结构那一层需要 CPU 回收。

**走廊在动，人不动。** XR 里移动相机就是晕车的配方。推进做成把整条走廊往人身上推：
着色器里 `aA.z + uRideZ` 一行，每帧只改一个 uniform，几千段线的实例数据一个字节都不用碰。

**线要自己扩成四边形。** `gl.lineWidth` 在 ANGLE 上恒为 1px，所以每段线在顶点着色器里
扩成正对相机的四边形。扩张放在**视图空间**（法线取 `cross(线方向, 到该点的视线)`），
不是裁剪空间——走廊会从人身上穿过去，裁剪空间的做法一碰到 `w<0` 就翻面。

**引力透镜画的是次级像。** 粒子渲染器不能弯折光线，但可以把「光绕过洞之后看起来来自哪个
方向」直接画出来：在 相机–洞–粒子 构成的平面内，用罗德里格旋转把视线方向转到光子球的角
半径附近。盘的远侧因此被拱到洞的上方和下方——那条光弧才是「像黑洞」的来源，不是多普勒。

## 踩过的坑

- **加法累积必须接 tonemap。** 密集处会冲过 1.0 硬截断成一坨死白。
- **稀疏采样做辉光会留下结构性伪影。** 忘了每像素抖动起始角，每个亮点就被复制成 N 个
  排成螺旋的副本；加了抖动之后仍有采样噪声（稀疏光源上方差极大），在 1/4 分辨率上放大
  回来就是马赛克。最后换成逐级降采样才彻底干净——**这类问题要换算法，调参数没用**。
- **XR 里不要硬写世界坐标。** 没有地面追踪的 runtime 会把 `local-floor` 的原点报在头的
  位置，硬写 `y = 1.25` 就跑到头顶一米多去了。
- **不要把功能绑在 `squeeze` 上。** runtime 对「握拳」也会发 `squeeze`，于是握拳吸附的
  同时触发了别的动作。手势自己从关节算（指尖到腕的距离，用掌骨长归一化）更可控。
- **残影必须几何化。** 生成艺术常用的「不清屏、盖半透明层」在 XR 里会随头动糊成一片。
- **立体下辉光要按眼夹住采样范围**，否则左眼的光会漏进右眼。

## 性能

主要开销是 fill rate。面板底部实时显示 `fps · 粒子数 × 拖尾段数 = 总点数`。
跑不动时按这个顺序砍：**拖尾长度 → 笔触大小 → 粒子量**。笔触大小是平方级影响填充率。
