# 像素村落 · WebXR 2.5D 像素风沙盘

太行山里的石头村，秋收的黄昏：院子沿等高线嵌在梯田山坡上，弯曲的石阶路，溪上一座石拱桥；28 个体素小人按职业过日子，几十只体素动物。纯 three.js，无构建步骤。

**▶ [打开](https://zhao0424.github.io/webxr-todo/pixel-village/)** · [村民档案](https://zhao0424.github.io/webxr-todo/pixel-village/roster.html) · [体素演员表](https://zhao0424.github.io/webxr-todo/pixel-village/cast.html)
— 电脑上拖动旋转、滚轮缩放、点人看档案；头显里点 ENTER VR。`?time=6` 从早上六点看起；`?event=opera|market|bonfire|harvest|movie|shrine|meeting` 指定今天的活动（比如 `?time=8.6&event=market` 看赶集）；`?weather=sunny|cloudy|rain` 指定天气。

## 运行

```
node serve.mjs                 # http://localhost:8080/
node check.mjs                 # 无头检查主场景：报错 + draw call + 截图到 shots/index.png
node check.mjs sheet           # 2D 角色表（体素小人的三视图来源），加 Q='?s=8' 放大
node check.mjs cast            # 体素演员表：28 人 + 全部动物，?t= 走路相位 ?yaw= 转角
Q='?cam=x,y,z,tx,ty,tz' node check.mjs index shots/close   # 指定相机截近景
```

PC 上的 Chrome 打开页面 → ENTER VR（Chromium → OpenXR → VITURE runtime）。
进入后沙盘在头正前方 1.05 m、视线下方 0.38 m；扳机 / 捏合重新摆。XR 里背景黑 = 光学透视眼镜上透明；`?sky=1` 保留天空。

## 比例

- 1 世界单位 = 村里 1 米；每米 18 像素（`TPU`）。成年人约 31 像素高（Q 版：头 11、身 9、腿 7）。
- 沙盘缩放 1:110（`UNIT = 0.009`）：90 × 72 米的村子在眼镜里约 0.8 × 0.65 米，人约 1.5 厘米高。

## 山村（`layout.js` 有总平面图和路网）

- 地形（`terrain.js`）：高度场 → 1.2 米一级的梯田（落差处是毛石堰）→ 按院子挖平台 → 路按 0.3 米取整成台阶 → 小溪 + 自动生成的石拱桥。
- 院落在 `compounds.js` 里按本地坐标建，`layout.js` 给位置和转角，平台高度取那里的地形。
- 人走路网（Dijkstra），高度跟着台阶和桥面。

## 一天的生活（`life/`、`residents.js`）

- 村里的钟（`life/clock.js`）：完整的一天，只是各时段走得快慢不一样——现实 1 秒 = 村里
  深夜 30 分钟（快进）· 清晨 5:00–6:30 1 分钟 · 白天 6:30–18:00 半分钟（放慢，人从村这头走到那头不至于花掉一个钟头）· 傍晚 18:00–21:30 0.75 分钟 ·
  21:30–23:00 2.5 分钟（各家一盏盏吹灯、打更）。整天现实约 36 分钟。`?time=` 从指定钟点开始（默认 15:30）。
- 日光（`daylight.js`）：深夜月光 → 拂晓（东边粉紫）→ 日出 → 上午 → 正午 → 午后 → 黄昏 → 掌灯 → 深夜；太阳早上在东、傍晚落西。
- 全天日程：`residents.js` 里每人的 `day` 是下午到夜里，文件末尾的 `MORNING` 是上午和中午，两段拼起来——
  媳妇们天不亮做早饭、喂鸡、下地，十一点回去做午饭；中午各家端碗到门口墙根吃（饭场），吃完歇晌；匠人一早开工，
  豆腐坊四点多就磨上了；孩子上午上学；羊倌一早赶羊上坡；小六子天一亮熄火把，晚上提着灯笼打更。
- 走路：剩下的路超过 12 米快步走（1.4 倍，步子也迈得快）；赶去参加活动、刚散场往回走的也快步走一阵。
- 28 个村民各有档案（全名、年龄、关系、职业、性格、来历、家当）和日程，日程里的活动见 `labels.js`：
  上课、打铁、拉风箱、磨豆腐、挑水、喂鸡喂猪、下地、挑谷子、轧场、放羊、端碗在门口吃饭（饭场）、戏台前凑热闹、点火把、回屋……
- 每个活动是一串任务：走过去（导航网格 A*）→ 干活 / 坐 / 蹲 / 说话 → 进屋（隐藏）。
- 动物响应人：喂鸡鸡围过来、羊跟着羊倌上坡、牛跟着去场院并拉碾子、驴只在磨豆腐时推磨、狗跟主人、鸭鹅被赶回家、猫和喜鹊在高处跳。
- 院门有人走近就推开，走远再关上。
- 人和动物的位置不按像素网格取整（取整会一顿一顿地走）；朝向先平滑转过去再按 22.5° 分档，带回差，拐弯不来回抖。
  路上有人（正前方 0.75 米、左右偏不到 0.45 米）：
  - 他也在走：旁边有地方就斜着绕过去——同向就是超车（跑得快的小孩不会堵在老人后面），迎面就各往外侧擦肩；
    旁边没地方，同向就放慢跟着走（不停），迎面在窄路上错不开才由一方让一下。
  - 他站着：先请他往旁边让一步（让完回原位接着干），能从旁边绕就直接绕；等 0.8 秒还挡着就把附近站着的人当临时障碍重新找路；
    绕不开才侧身挤过去。
  - 绕人偏出了路线、直着回不去时重新找路。停下至少停 0.3 秒（不会每帧在走 / 停之间切换看着发抖）；站着的人之间至少隔 0.7 米。
  - 动物同理：路上遇到人从旁边绕，绕不过去就放慢或稍等，等久了才挤过去（领头的羊倌、主人、喂食的人不用绕）。
  - 模拟统计 `queue`：走路时间里站着等人的比例，现在约 0.4–0.8%。
- 小孩玩耍：村口空场、追别的孩子、围着货郎，还会去溪北岸蹲着玩水打水漂、钻进村子附近的庄稼地逮蚂蚱。
- 炊烟：屋里有人（烧炕、做饭）才冒；豆腐坊的蒸汽只在煮浆时冒；铁匠炉的烟囱有人打铁才冒。停的时候已经飘出去的几团照样飘完。
- 动物走路：换了目标才判断一次能不能直着走，不能就 A*，然后沿着这条路走完（不再每帧在直走 / 绕路之间切换）；
  一帧的步长用完为止，过拐点不停顿；擦着墙角就沿一根轴滑过去；真卡住 0.8 秒重新找路；门关上时正站在门洞里的可以挤回去。
- 坐门口、端碗蹲门口吃饭：坐到院门两边的墙根底下（不是路面、不在门前平台上），一人一个位置，不挡道。
- 动物、小孩只去和村子连通的地方（`nav.reach`：从井出发能走到的格子）；动物离家远时搜全图找路，困在不连通的小角落就近跳出来。

## 日子、天气、每天的变化（`life/events.js`、`life/variety.js`）

- 农历：第 1 天是九月初四，时钟栏显示"九月初五 晴"。逢五逢十赶集，其余日子轮着其他活动。
- 天气：头一天晴，之后晴六成、阴两成半、小雨一成半（按天固定）。阴天、雨天太阳弱、天发灰；雨天三千根雨丝、白天屋里也点灯，
  户外的事（下地、放羊、闲坐、下棋、玩……）改成待在屋里，户外活动"下雨，改天"；做饭、喂牲口、上学、铺子里干活照常，
  出门撑油纸伞；鸡钻回窝，牲口不往外溜。
- 每天不完全一样（按天、按人、按日程条目固定）：学堂逢十放假；杨二哥、吴大哥、刘木匠隔三差五进山砍柴（扛斧子上坡、背一捆柴回来）；
  媳妇们隔几天去溪边洗衣裳（蹲着搓、回院晾）；老人有时去老伙计家串门。
- 人际关系（`residents.js` 的 `FRIENDS`：下棋的老伙计、常串门的媳妇、手艺人、男孩一伙女孩一伙）：
  看戏、篝火、闲聊挨着自家人和要好的占位置；孩子先找自己那一伙玩；老人串门找老伙计；狗跟着主人去看戏、赶集，到了在脚边待着。
- 散场错开：没角色的人离场时间前后错开（提前 13 分钟到留下 23 分钟），不再一窝蜂。
- 夜里的灯：各家 21:18–22:36 之间按自己的钟点一盏盏吹灯，学堂李先生、药铺周郎中睡得晚，最后只剩他们和打更的灯笼；天不亮做早饭时又点上。
- 随机数全部带种子：同样的 `?time=…&sim=…` 每次结果一样，问题能复现。

## 界面（`src/ui/`）

参考潜水员戴夫：深色面板 + 亮的细边，正文奶白、名字金黄、标签是压低饱和度的实色小块（切掉四个角）；配色取场景黄昏的紫。
- 两个像素单位，都落在整数个屏幕像素上：`--f` 是字的一个点（1 个设备像素，高分屏 2 个），`--p` 是边框和间距的一个像素（= 2 个 `--f`）。
- 面板、凹进去的内框、头像框是代码画的 10×10 像素 9 宫格边框图（`frame.js`），多大都清楚。
- 字体：凤凰点阵体 16px（Haoyu Qiu，CC0 公有领域，`fonts/LICENSE-vonwaon.txt`），按原大小显示，标题用 2 倍或"加粗"（往右多描一个点）。
  用 `python tools/subset-font.py` 裁成只含项目里用到的字（约 115 KB）；字体缺的几个符号（· — ▸ ✓）借相近的字形顶上。
  加了新文字要重跑一次，不然新字会落回系统字体。
- 村子里点村民：头像、名字、身份标签、"此刻"（正在干什么、在哪儿、接下来）、来历；性格喜好、手艺家当、亲近的人（点名字跳过去）、
  今天的安排（按清早 / 上午 / 中午 / 下午 / 晚上分段，当前那条高亮）都收在可折叠的抽屉里。头顶出现一个上下跳的黄箭头。
- 点小动物：名字（每只都有，`animalInfo.js`）、品种、谁家的、此刻在干什么、来历；狗能点到主人。
- 村民档案（`roster.html`）：深紫底（和最早的档案页同色），按户分组；每人一张卡：全身像、名字外号、职业和家里身份、年龄性别、性格标签、
  来历、喜欢、手艺、家当，家里的牲口列在每户底下；能按大人 / 老人 / 孩子 / 手艺人 / 种地的 / 外来的筛选；点卡片弹出完整的卡（亲近的人、一天的安排）。
- 截图检查：`?pick=村民id`（或 `?pick=beast:序号`）一打开就弹出那张卡，`&unfold=1` 把抽屉都展开。

## 剃头挑子（`life/barber.js`）

"剃头挑子一头热"：村口挑子这头小炭炉烧着一盆热水（柱子上搭毛巾、挂荡刀皮条），那头是客人坐的凳子。
每天挑 4 个客人（男人、老人、男孩轮着）、各有一个大概的钟点；到点手头的事放得下（不是做饭、上课、放羊、轧场、磨豆腐、吃饭、
在活动上有角色……）就过来：先蹲在一边等，轮到了坐上凳子，剃头匠站到后头剃头 → 刮脸 → 掏耳朵，完了客人回去接着干原来的事
（村民的"临时差事"：`interrupt()` / `finish()`）。没客人时荡刀子、吆喝、歇着；剃头匠不在就不接活。白天的活动他守着挑子不去。

## 戏台、火塘（村口）

每天轮一样：唱戏 → 篝火讲古 → 开村会（`?event=opera|bonfire|meeting` 指定；时钟旁边显示"今晚村口"）。
- 唱戏：羊倌老马拿着扇子上台唱，剃头匠老郑坐台上的椅子拉板胡；台下以台口为圆心一圈圈站（小孩蹲最里圈），
  老人坐石桌边，火塘边的石头、石凳也坐人；有人叫好。
- 篝火：老郑先把火点上，坐在火塘西边讲古；其他人坐石头、石凳围一圈，坐满了外圈站着。老郑回家火就灭。
- 村会：村长站台上讲，李先生坐椅子记账；户主必到，小孩不来。
- 不是人人都去：按年纪、性别、身份、喜不喜欢听戏掷骰子（同一天结果固定），不去的在自家门口坐着或早歇；
  位置一人一个、从里圈往外占，占满了也不去挤。
- 戏台能上：从台阶走上去（`climb` 任务，导航网格管不到的台上、凳上走直线），下一个活动开始时原路下来。
- 台上"一桌二椅"摆在台口那半边，屋檐挡不住，从上往下看得见。
- 档案：`roster.html`；村子里点一个人弹出他的卡片和"正在干什么"。

## 自检（每次改布局后跑）

`node check.mjs` 会输出 `audit=`，四项都应为空（另有 `coplanar.left` 应为 0）：
- `floating`：贴地摆放的东西，底下四角的地面低了一截（悬空）
- `unreachable`：某个院子从门外走不到的房门 / 干活位置 / 井
- `islands`：和井不连通的路网节点（附近的地面高度一并列出）
- `brokenEdges`：走不通的路（沿线每 0.5 米的地面高度，`#` = 挡着）
- `coplanar`：共面闪烁（z-fighting）。建村时（`coplanar.js`）把所有方块的面、棱柱的顶面 / 底面 / 侧面、贴花算到村子坐标，
  找"朝向相同、相距不到 4 毫米、投影有重叠"的面对（门柱和墙、墙的拐角、墙头和压顶、交叉的石板路……第一次查出 657 处），
  同一平面里按面积从大到小排，最大的不动，其余的只把这一面往外推 1.2、2.4……厘米（柱子径向撑粗、贴花沿法线挪），
  修完再查一遍，`found` 是修之前、`left` 是修之后。
- `perchFix`：猫、喜鹊的落脚点从上往下打射线贴到真实表面（屋面、墙头、缸沿、树冠），列出改动过的点

院子都放在自己的平台以内：广亮大门的门楼缩在墙线里，杂货铺门口的缸和凳子在平台上；
每个院门外铺一块和院里一样高的门前平台，接到路网节点；路只能压平台外沿、不能压平台核心。

## 门

院门（广亮门、随墙门、柴门、作坊的木板大门）和栅栏门（羊圈、菜园）都能开合。门洞是导航里的"门格子"：
关着时动物过不去；人走到门前会停下推门，门开了才过；赶着的牲口没过完门就一直开着。
狗、猪、羊、驴、牛会把门拱开（偶尔溜出院门转两圈再自己回来），但不会关——门就敞着，直到有人从门口过顺手带上。
鸡鸭不会拱门，门敞着时也只在自己的地盘里转。石磨、碾子只有上扇磨盘 / 碾滚和拉杆转，底座不动。

## 防穿模（`nav.js`）

- 0.25 米导航网格：房子、墙、栅栏、道具、树干按真实朝向投影成障碍；高差 > 0.35 米（石堰）不能走，0.3 米台阶能走；水只有鸭鹅能下。
- `Q='?sim=330&time=15' VT=150000 node check.mjs index shots/sim`：后台快进模拟，输出站进障碍的次数（按人 / 活动归类）、圈养牲口跑出院子的次数（escaped）、门被推开的次数。
- 干活时站在物件跟前、脸朝物件；工具按家伙分动作（锤子砸、锯子拉、锄头锄、勺子搅、扫帚扫……），握在手里朝前伸。`cast.html?only=id,id&pose=work&zoom=7` 放大看。

## 灯光（`daylight.js`）

- 午后 → 黄昏 → 掌灯 → 月夜，太阳、天光、天空、远山跟着变。
- 天黑后：窗户亮（家里有人、在做饭更亮）、灯笼和光晕亮、小六子挨个点路口火把（火苗 + 光晕 + 地面光斑），戏台 / 杂货铺 / 铁匠炉 / 桥头有真实点光源。

## 种植养殖（`farmland.js`）

- 梯田里种着体素庄稼（实例化）：玉米、红高粱、谷子、白菜，麦茬地里立着麦个子，南滩是赵家的大豆。稻草人、看青棚。
- 各家：牛棚、驴棚、猪圈、鸡窝、兔笼、鸭棚、蜂箱、菜园、玉米架、羊圈和羊棚。

## 体素人物和动物（`voxel.js`）

- 人：用 `characters.js` 画的正 / 侧 / 背三视图做视觉外壳雕刻，表面取对应视角的像素颜色；腿、胳膊、手持物拆开绕关节转。
- 动物：侧视图按到轮廓的距离"充气"出厚度，按 Q 版比例放大。
- 树：隐函数体素（椭球 + 噪声），按朝夕阳的程度分档上色。

## XR 里像素风的规则

1. **统一像素密度**：所有贴图按 TPU 绘制，方块 UV 以米计。
2. **在材质里做像素化，不用屏幕后处理**：`EffectComposer` 不支持 WebXR；`pixelize()` 改写采样，硬边、头动不闪。
3. **色相偏移的色阶** 替代后处理调色；**自发光 + 像素光晕** 替代 bloom；**远山大气透视** 替代景深。
4. **统一描边**：方块用反向外壳、精灵用像素描边，同色同粗。
5. **动画按像素一格一格走**。
6. **精灵统一朝向**：每帧按头的位置算一次，左右眼一致；人物按"相对观察者的走向"选正 / 背 / 侧面帧。
7. **静态合批**：上千个方块按材质合成几十批（XR 每个网格要画两遍）。

## 扩展

- 加人：`residents.js` 里加一条（外观字段见 `characters.js` 顶部），`day` + `MORNING` 决定他每天去哪。
- 加活动：`life/events.js` 的 `EVENTS` 里加一条（时间、地点、角色、去的概率）+ `EVENT_ACTS` 里写去了干什么，再加进 `ORDER`。
- 加院子：`compounds.js` 照现有的写，返回 `spots` 让人能走进去。
- 加动物：`animals.js` 加字符画，在院落的 `animals` 里放。
