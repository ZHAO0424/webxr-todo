# 像素村落 · WebXR 2.5D 像素风沙盘

太行山里的石头村，秋收的黄昏：院子沿等高线嵌在梯田山坡上，弯曲的石阶路，溪上一座石拱桥；33 个体素小人按职业过日子（村里 28 个，东边老村址 5 个），几十只体素动物。纯 three.js，无构建步骤。

**▶ [打开](https://zhao0424.github.io/webxr-todo/pixel-village/)** · [村民档案](https://zhao0424.github.io/webxr-todo/pixel-village/roster.html) · [体素演员表](https://zhao0424.github.io/webxr-todo/pixel-village/cast.html)
— 电脑上拖动旋转、滚轮缩放、点人看档案；头显里点 ENTER VR。`?time=6` 从早上六点看起；`?event=opera|market|bonfire|harvest|movie|shrine|meeting` 指定今天的活动（比如 `?time=8.6&event=market` 看赶集）；`?weather=sunny|cloudy|rain` 指定天气。
屏幕左边的"西沟"按钮（或键盘 ←）往西走到[西沟](#西沟westjs)，右边"老村址"（→）往东走到[老村址](#老村址eastjs)；`?scene=west` / `?scene=east` 直接从那一块开始。
左下角"设置"里的"季节"按钮按春 → 夏 → 秋 → 冬轮换（重新加载页面）；`?season=spring|summer|autumn|winter` 直接指定，默认秋天。见[四季](#四季seasonjs)。

## 运行

```
node serve.mjs                 # http://localhost:8080/
node check.mjs                 # 无头检查主场景：报错 + draw call + 截图到 shots/index.png
node check.mjs sheet           # 2D 角色表（体素小人的三视图来源），加 Q='?s=8' 放大
node check.mjs cast            # 体素演员表：28 人 + 全部动物，?t= 走路相位 ?yaw= 转角
Q='?cam=x,y,z,tx,ty,tz' node check.mjs index shots/close   # 指定相机截近景
Q='?scene=west' node check.mjs index shots/west            # 西沟：输出里多一行 west=（建造耗时、合批、树、悬空、物件）
Q='?seam=1&cam=-0.42,0.5,0.62,-0.42,0.02,-0.05' node check.mjs index shots/seam   # 两块都画，看村子和西沟的接缝
```

PC 上的 Chrome 打开页面 → ENTER VR（Chromium → OpenXR → VITURE runtime）。
进入后沙盘在头正前方 1.05 m、视线下方 0.38 m；快速捏两下（0.4 秒内两次扳机 / 捏合）或系统重新定位时，沙盘用半秒滑回眼前（不瞬移）。每只手一条细射线（比手的指向朝下 20°，手不用抬高就能指到桌上的沙盘；点选、路牌都按这条线），指着东西时落点有个像素小光点（捏住时变大），双手握住时藏起来；射线落点每只手每 4 帧测一次，大网格载入后空闲时建 BVH（three-mesh-bvh，`indirect` 不改网格索引），一次检测从 15 ms 降到 0.5 ms。单手捏一下 = 鼠标点一下：指着人、动物、房子物件就在它头顶（深度也和它一样）弹出和网页上同一张卡片，指着空处收起；卡片正对眼睛、不做深度测试（不会插进房子里），离得远自动放大；双手握住拖、转、拉近推远或沙盘滑回眼前时卡片收起（`ui/xrCard.js`：卡片 DOM 连同 ui.css 和点阵字体塞进 SVG foreignObject 画成贴图，内容变了才重画，最多一秒一次；`?xrcard=1` 桌面上也画出来检查）。XR 里背景黑 = 光学透视眼镜上透明；`?sky=1` 保留天空。
双手同时捏合 = 握住沙盘（`xr.js`，手感照 HexCity 的 CityGrip / Skyvine）：两手一起动 = 平移；两手拉开 / 收拢 = 沿视线拉近 / 推远（0.35–3 m，不改缩放）；两手连线转动 = 绕竖轴转（水平转、绕着胸前转、方向盘式上下错动都行，水平转角 1:1 跟手）。从握住起累计两手的运动来分类，定了到松手不变：连线转过 8° 算转；中点挪够 3 cm 且连线转得不到 4° 算平移；间距变化比中点挪动大 1.5 倍算推拉；分清之前已做出的那段平移 / 转动在接下来几帧补上。转看连线角度而不看手走多远——绕胸前转时中点也在横移，两手一起拖时一只手慢半拍连线也只歪两三度。刚捏上的 150 ms 不算（手指收拢时捏合点会跳）。
每次握住后第一下分清是哪种就锁定到松手，不会拖着拖着变成转；握过的这一下松手不算捏合。
阴影贴图隔帧重画（人在走），太阳也只在重画那帧挪；太阳挂在沙盘下跟着一起动，所以拖、转、推拉时贴图不用重画，只是每帧按沙盘当前位置补算一遍阴影投影矩阵（three 只在重画那帧算它，不补的话一动影子就一闪一闪）。有手部追踪（进 XR 时申请 `hand-tracking`）用拇指尖和食指尖的中点，没有就用手柄位置。
沙盘左右两侧各插一块木路牌（画着箭头和那边的样子），扳机 / 捏合指着路牌就换场景，这一下不重新摆沙盘。`?signs=1` 在电脑上也显示路牌。

## 比例

- 1 世界单位 = 村里 1 米；每米 18 像素（`TPU`）。成年人约 31 像素高（Q 版：头 11、身 9、腿 7）。
- 沙盘缩放 1:110（`UNIT = 0.009`）：90 × 72 米的村子在眼镜里约 0.8 × 0.65 米，人约 1.5 厘米高。

## 山村（`layout.js` 有总平面图和路网）

- 地形（`terrain.js`）：高度场 → 1.2 米一级的梯田（落差处是毛石堰）→ 按院子挖平台 → 路按 0.3 米取整成台阶 → 小溪 + 自动生成的石拱桥。
- 院落在 `compounds.js` 里按本地坐标建，`layout.js` 给位置和转角，平台高度取那里的地形。
- 人走路网（Dijkstra），高度跟着台阶和桥面。
- 村口南边插进了一条 6 米宽的地（`layout.js` 的 `BAND`）：z ≥ 26 的东西（小溪、石拱桥和桥头两个路口、溪南草滩、场院）都往南挪了 6 米，
  两块沙盘底座都跟着加长（z 到 42）；地形用 `squeeze` 把新坐标折回原来的坐标算高度，所以以北一点没变。村口场子往南接了一块一样高的平地
  （`compounds.js` 的 square 多铺一块地皮、`village.js` 多压一块平台），场子南口挪到新那块的南沿，去西边的路绕它的西南角（`sqSW`）。
  新那块平时也有东西：戏台正对着三排木条凳（中间留过道，18 个座，看戏、开会、看电影大人先坐条凳，坐满了站后头）；
  条凳能搬（不合批，`village.js` 的 `benches`）：赶集那天周六子、小顺先来摆场子（集市活动里的角色），一条一条扛在肩上搬到东边两条一摞；
  散了集叫其中一个来一条条搬回去（`activities.js` 的 `moveBenches`）。扛起来那条不挡路，放下的地方才挡路；中途被叫走，肩上那条直接放到要去的地方。
  西边是晒场（2 × 2 四张晒席，中间一条走道；春天空晒席，夏天晒麦粒，秋天晒玉米、谷子、红辣椒，冬天码柴火）。看戏的站位、火塘外圈、孩子玩的地方也扩到了南边。
  场院北边一排三张晒席，南边两个碾净扬净堆起来的大圆锥粮堆（三十度上下的坡，堆尖撒白石灰的灰印、插着木锨），一排粮袋、簸箕；按季节换粮食，春冬只剩粮袋 / 麦秸垛（打场站人的点躲开它们）。
  村口古槐的树干是单独的形状（`voxel.js` 的 `gnarl`）：粗短的圆树干带竖棱和树瘤、微微歪，接地处喇叭口扎开，伸出五条贴地的板根；
  树干根部最粗、往上一路收细，到半腰分杈，每一团树冠都有一根粗枝（二次曲线，越往外越细）斜着伸进去，树冠不会悬空；树冠压得比较低，树干露出来的部分和树冠比例匀称。叶子颜色和村里别的槐树一样（春天开白槐花，冬天光枝）。
  西沟一起加长（`west.js` 的 `ground` 同样按 `squeeze` 折回原坐标）：小溪、拦河坝、水轮、水磨坊跟着溪往南挪，两块拼起来（`?seam=1`）是对得上的。

## 一天的生活（`life/`、`residents.js`）

- 村里的钟（`life/clock.js`）：完整的一天，只是各时段走得快慢不一样——现实 1 秒 = 村里
  深夜 30 分钟（快进）· 清晨 5:00–6:30 0.75 分钟 · 白天 6:30–18:00 0.35 分钟（放慢，人从村这头走到那头不至于花掉一个钟头，干活、串门的时间更宽裕）· 傍晚 18:00–21:30 0.55 分钟 ·
  21:30–23:00 2 分钟（各家一盏盏吹灯、打更）。整天现实约 50 分钟。`?time=` 从指定钟点开始（默认 15:30）。
- 日光（`daylight.js`）：深夜月光 → 拂晓（东边粉紫）→ 日出 → 上午 → 正午 → 午后 → 黄昏 → 掌灯 → 深夜；太阳早上在东、傍晚落西。
- 全天日程：`residents.js` 里每人的 `day` 是下午到夜里，文件末尾的 `MORNING` 是上午和中午，两段拼起来——
  媳妇们天不亮做早饭、喂鸡、下地，十一点回去做午饭；中午、傍晚各家端碗坐在自家门槛上、门口墙根底下吃，脸朝外看着街上（饭场），吃完歇晌；匠人一早开工，
  豆腐坊四点多就磨上了；孩子上午上学；羊倌一早赶羊上坡；小六子天一亮熄火把，晚上提着灯笼打更。
- 走路：剩下的路超过 12 米快步走（1.4 倍，步子也迈得快）；赶去参加活动、刚散场往回走的也快步走一阵。
- 28 个村民各有档案（全名、年龄、关系、职业、性格、来历、家当）和日程，日程里的活动见 `labels.js`：
  上课、打铁、拉风箱、磨豆腐、挑水、喂鸡喂猪、下地、挑谷子、轧场、放羊、端碗在门口吃饭（饭场）、戏台前凑热闹、点火把、回屋……
- 每个活动是一串任务：走过去（导航网格 A*）→ 干活 / 坐 / 蹲 / 说话 → 进屋（隐藏）。
- 动物响应人：喂鸡鸡围过来、羊跟着羊倌上坡、牛跟着去场院并拉碾子、驴只在磨豆腐时推磨、狗跟主人、鸭鹅被赶回家、猫和喜鹊在高处跳（只跳中间没隔着房子的，弧线越过屋檐；杂货铺的猫走屋脊到檐口再跳到门口缸上）。挑担子的扁担前后顺着搭在右肩上。
- 院门有人走近就推开，走远再关上。
- 人和动物的位置不按像素网格取整（取整会一顿一顿地走）；朝向先平滑转过去再按 22.5° 分档，带回差，拐弯不来回抖。
  路上有人（正前方 0.75 米、左右偏不到 0.45 米）：
  - 他也在走：旁边有地方就斜着绕过去——同向就是超车（跑得快的小孩不会堵在老人后面），迎面就各往外侧擦肩；
    旁边没地方，同向就放慢跟着走（不停），迎面在窄路上错不开才由一方让一下。
  - 他站着：先请他往旁边让一步（让完回原位接着干），能从旁边绕就直接绕；等 0.8 秒还挡着就把附近站着的人当临时障碍重新找路；
    绕不开才侧身挤过去。
  - 绕人偏出了路线、直着回不去时重新找路。停下至少停 0.3 秒（不会每帧在走 / 停之间切换看着发抖）；站着的人之间至少隔 0.7 米。
  - 动物同理：路上遇到人从旁边绕，绕不过去就放慢或稍等，等久了才挤过去（领头的羊倌、主人、喂食的人不用绕）。
  - 模拟统计 `queue`：走路时间里站着等人的比例，现在约 0.4–0.8%。
- 货郎钱小二挑的是货郎担：右肩一根长扁担，前后各一只带腿的木货柜（两排抽屉、铜拉手、顶上围栏货盘、门字架上挂拨浪鼓和头绳），停在门口时摇拨浪鼓。
- 钓鱼（`fish`）：举着竹竿去溪北岸坐着（和洗衣裳的抢同一排岸边位置），腿伸向水面，竿梢垂线和红白浮子，隔一阵提一下竿。
  老把式陈满仓（技能里有钓鱼）上午走去西沟瀑布下的水潭，坐在南半圈岸上、脸朝潭心；孙栓子放学后在村边溪里钓。下雨不去。
- 鸭鹅：溪里、溪北岸，往西到铁匠铺门口那片草滩。那片草滩人走不下去（没修路），鸭鹅碰上石堰、溪岸这种 1.5 米以内的坎就扑腾着抛物线跳上跳下（`nav.js` 的 `hop`，找路时跳一次坎很费劲，有平路先走平路；活动范围用 `nav.flood` 从溪里按能游、能跳算出来）。
- 天黑了还在西沟深处（离村子 30 米开外）的人不赶回去，就近在水磨坊或山神庙里过一夜，第二天一早从那儿出来；卡片上写在哪儿过夜。
- 小孩玩耍：村口空场、追别的孩子、围着货郎，还会去溪北岸蹲着玩水打水漂、钻进村子附近的庄稼地逮蚂蚱。
- 炊烟：屋里有人（烧炕、做饭）才冒；豆腐坊的蒸汽只在煮浆时冒；铁匠炉的烟囱有人打铁才冒。停的时候已经飘出去的几团照样飘完。
- 动物走路：换了目标才判断一次能不能直着走，不能就 A*，然后沿着这条路走完（不再每帧在直走 / 绕路之间切换）；
  一帧的步长用完为止，过拐点不停顿；擦着墙角就沿一根轴滑过去；真卡住 0.8 秒重新找路；门关上时正站在门洞里的可以挤回去。
- 坐门口、端碗蹲门口吃饭：坐到院门两边的墙根底下（不是路面、不在门前平台上），一人一个位置，不挡道。
- 动物、小孩只去和村子连通的地方（`nav.reach`：从井出发能走到的格子）；动物离家远时搜全图找路，困在不连通的小角落就近跳出来。

## 路边景观（`roadside.js`）

- 石阶路两边的草坡上长野花野草：狗尾巴草、野菊、紫菀、蒲公英、草丛、碎石，离路越近越密（实例化体素，约 1300 棵，6 个 draw call）。
- 桥头土地庙、几个丁字路口的石敢当、几家院门两边的花盆（都找平地放，参与悬空自检）。

## 西沟（`west.js`）

出了村西口、翻过山梁，小溪往下游流进一道山沟。和村子同一个世界坐标（x 从 -135 到 -45，接在村子西边），沙盘一样大。
`west.js` 顶上有总平面图。

- 地形照村子的做法（`buildTerrain` 换了几样：范围、自然地面、水、落差侧面的材质），东边 8 米渐变到村子的地形，交界处高度完全一样。
- 红石崖：崖壁是一层层微微起伏的红砂岩（`R.rock`）。崖上只有右边（古道顶上）一段是 22 米的平台，往西是起伏的石头山，
  离崖边越远越高；石缝里长着松柏、黄栌。
- 挂壁古道：崖腰 15 米的平台，往西顺着崖脚斜下去接到林子里。中间一段凿进崖里：头顶一整块崖石（离洞口 3 米以内一级级往崖里收，顶面接着崖顶的草坡铺草、零星露岩，外沿一道岩边；崖顶边上那道裸岩有宽有窄），外侧一排窗洞；
  两头是明路，外沿砌矮石墙。
- 山神庙：在古道上方的半崖（18.6 米）往里凿一个口宽里窄的深龛，木头小庙（木板墙、红柱前廊、灰瓦顶、檐角上翘）整个缩在里面；
  龛上面的山一级级往后退着升高。门前一截木栈台挑出崖面、悬在古道上方，底下木梁插进崖里、斜撑顶着，西头一座小钟亭。
  古道边一段凿在崖里的石阶上去。
- 瀑布：后山泉水顺着山沟一级级流到崖边，直落进崖脚的深潭（跌水面往下滚动、潭边冒水雾）。潭水顺着山沟一级级跌下去（水面高低不一，
  落差处自动画成跌水），汇进南边的小溪。
- 水磨坊（东边小溪北岸，照太行山里的老磨坊）：挖低一级贴着水面；毛石墙基、土坯墙、石板顶的正房（烟囱、匾，檐下挂柿子串、辣椒串）
  + 西边一座敞着的磨棚（坡顶上晾柿饼、山楂片）。上游一道拦河石坝把水拦高一级，坝下的大水轮（两圈轮缘、宽刮水板，
  占三分之二的河道，比人高）一格一格转；水轮前后那段河道拉成直的，轮子不戳进河岸。传动看得见：轮轴架在岸边石墩上伸进磨棚，
  轴头的大立齿轮拨着灯笼齿轮，竖轴穿过磨台带着上扇磨盘转（转得比水轮快一倍多），磨盘上吊着粮斗。夜里窗户和灯笼亮。

## 老村址（`east.js`）

出了村东口，顺着小溪往上游绕过山嘴，河谷一下子宽了——石峪村原来就在这儿，叫"老石峪"。六十多年前一个夏天连下七天雨，
山洪从上游的山口冲下来，从村子当中冲出一条新河道，塌了大半个村子；大半人家搬到下游现在的地方，老村址只剩几户守着。
这块沙盘留给「创建居民」建出来的新人：12 处老宅（村里各家的祖宅）空着，可以选来住、慢慢修起来。

- 地形：和村子一样是一面北高南低的坡，一级级黄土坎子。**黄土冲沟**（`OLDBED`、`gullyDepth`）：当年的山洪从东头山口刨出一道 5–8 米深的沟，
  斜劈过坡，沟口开在湖边；两岸陡立的黄土崖、崖边一溜树，沟底草和柳树、一条小路、冲下来的石碾；老街在沟上过一座**土拱桥**。
- **东南角一大片湖**（`shoreZ`、`lakeR`）：一直铺到沙盘东边、南边的边上，岸边一圈毛石驳岸（`quay`）、两处石头码头，浅水里一丛丛芦苇（四季变色），北岸沙滩、几片竹子和柳树；
  南边的小溪只剩西边一段，在湖西头漫过一道**小石坝**（`DAM_U`）跌进湖里——湖面（`LAKE_Y`）比溪低 0.3 米。
  湖水用自己的材质（`lakeWaterMaterial`，冬天除外）：按离岸远近分四档颜色，斜看映天色，短横波纹慢慢漂，岸边碎浪花，夜里波纹映月光；都按一米 18 像素算，不用后处理。
- 夜里和村里一样：煤窑口、进山口、山货场、土拱桥头点火把，原住户门口挂灯笼杆、河神庙檐下一对红灯笼，有人住的屋子窗前有光晕。

### 换场景（`scenes.js`）

三块沙盘（从东往西：老村址、村子、西沟）挂在同一个 `world` 组里。XR 路牌上的小画跟着那一头是哪块换。换场景时当前这块直接藏起来，空 0.25 秒，世界平移过去，新的一块出来——不做缩放之类的特效，两块不同时出现。
平时只画当前这一块（XR 里每个网格画两遍），另一块照样在模拟。

## 剃头挑子（`life/barber.js`）

"剃头挑子一头热"：村口挑子这头小炭炉烧着一盆热水（柱子上搭毛巾、挂荡刀皮条），那头是客人坐的凳子。
每天挑 4 个客人（男人、老人、男孩轮着）、各有一个大概的钟点；到点手头的事放得下（不是做饭、上课、放羊、轧场、磨豆腐、吃饭、
在活动上有角色……）就过来：先蹲在一边等，轮到了坐上凳子，剃头匠站到后头剃头 → 刮脸 → 掏耳朵，完了客人回去接着干原来的事
（村民的"临时差事"：`interrupt()` / `finish()`）。没客人时荡刀子、吆喝、歇着；剃头匠不在就不接活。白天的活动他守着挑子不去。

## 买卖（`life/economy.js`、`life/trade.js`）

设计和调研（参考用户的 TownSnyty、Doran & Parberry《Emergent Economies for RPGs》、网络创世纪、Skinner 的乡村集市研究）：wikigarden `efforts/creative-coding/像素村落-经济与交易系统设计.md`。

- **按户算账**：一家人一个钱袋、一个存货；村口的剃头匠、货郎各自一户；骡帮算村外。货币是铜钱（文），也可以以物易物、赊账。
- **开局家底**：每户都存着够吃一个月上下的口粮（25～35 天，各家错开）、十天的柴、一个月的盐和火柴，开局几天照常过日子。买卖先从豆腐、青菜、剃头、修农具这些日常小事开始，存粮吃下去了才陆续有人去买粮。
- **手艺人和买卖人的进项**（缩小贫富差距）：
  - 铁农具 80 文、木器 50 文；修农具 6 文、修家什 5 文；
  - 杂货铺、货郎的外来货加五成卖；
  - 逢集骡帮在铁匠铺钉马掌（3 头 × 6 文），收山货时给杂货铺一成牵线钱。这两笔都是从村外进来的钱。
- **东西**：粮食、白面、豆子、豆腐、青菜、咸菜、鸡蛋、柴、盐、洋火、布、铁料、铁农具、木器、丸药、蜂蜜、羊毛、筐、烧饼、衣裳，各有底价。豆腐、烧饼当天坏，青菜、鸡蛋慢慢坏。
- **产出**：人在干活的位置上真干着（不是在走路），按产出表一点点攒，攒够一件进自家库存。比如磨豆腐、点卤出豆腐（要用豆子），打铁出农具（要铁料和柴），郎中做丸药（要蜂蜜），砍柴、种菜、下地、养蜂、编筐。有鸡的人家每天下蛋，有壮劳力的人家每天自己捡一捆柴。
- **每天凌晨 4:30 结一次**：
  - 吃用：按人头和季节；冬天吃咸菜不吃青菜，柴烧得多。
  - 放坏的扔掉。
  - 东西用坏、生病：锄头、筐、衣裳隔些日子坏一件，有人生病要看郎中。
  - 卖家调价：卖掉 ≥2 件且剩货 ≤2 涨一成，一件没卖且剩货 ≥5 降一成。夹在底价 0.5～2 倍之间；杂货铺、货郎的外来货加三成卖，不低于进价。
  - 列购物清单：缺的 = 目标存量 − 现有，再加上手头宽裕时添置的东西（白面、鸡蛋、家具、新衣裳），以及修农具、修家什这类手艺活。
- **看得见的买卖**（`trade.js`，照剃头挑子那套临时差事）：
  - 派差事先看这个人当天的日程，只挑他真闲着的时段（7 点到 18 点之间、至少半个钟点）。比如羊倌上午放羊、中午歇晌，就下午去；赶集日只排在下午。
  - 到了钟点，手头的事放得下，就挎上篮子去买。每人每天最多跑一趟；做饭、上课、吃饭、睡觉时不叫。原定的人一个钟点都抽不出空，就换家里别的闲着的人。
  - 卖家在摆摊、叫卖的地方，就走到跟前；在自家院里、作坊里干活的，就到院门口喊一声。
  - **货郎代买（跑腿）**：没空买东西的交给货郎钱小二。一整天都没闲着的时段、等了三个钟点都没抽出空的，以及家里只有 65 岁以上老人的（陈老汉老两口、周郎中），都算。
    - 他叫卖的间隙先到卖家门口取货，再送到买家院门口。家里有没有人都直接成交：钱从这户的钱袋里出，东西放进这户的存货。
    - 另收一文跑腿钱。头顶冒"代买 豆腐×2"，卡片上写"货郎代买"。
    - 修农具这类得本人拿着家伙去的手艺活不代办。
  - 当面说几句话就成交。卖家闲着会转过身来招呼。
  - 头顶冒像素气泡：买家头顶写"豆腐×2 4文""换鸡蛋×2""赊6文"，卖家头顶写"+4文"。买家拿着东西回家：豆腐端托盘，柴背在背上，粮食扛口袋。
- **新来的人开张**：干活用的原料可以先赊着（最多 60 文），卖了再还。
- **怎么付**：先付铜钱，钱不够全买就先买得起的那些；再不行，拿卖家缺的东西抵；两人熟的话赊账，赶集日结清。都不行就挂着，明天再说，连着买不着的记成"缺口"。
- **赶集**：村口三个摊子卖真货，豆腐摊是赵家的、杂货摊是货郎的、菜摊是吴家的。逛集的人按自家清单买。骡帮收山货（羊毛、蜂蜜、筐，钱进村），卖盐、铁料、布、火柴给杂货铺和货郎（钱出村）。
- **每月初一**：学费，每个孩子 3 升粮食加 20 文给李先生；地租，杨家、吴家种着王家的地，每家交 25 升粮食加 40 文（钱不够拿粮食抵）。剃头一回 2 文，看病 10 文，修农具 6 文，修家什 5 文。
- **接济**：哪家粮食见底、手里又没钱，跟他家最熟、有富余的那家送三天口粮（人情，不记账）。
- **熟识度**：两两一个数。买卖成交、串门、接济都会加。挑卖家时，熟识度能抵一部分价钱（熟客）；赊账要熟。
- **卡片**：点一个人，"此刻"写具体差事，比如"去赵家豆腐坊买豆腐"；下面一行是"今天：买了豆腐×1（2文）"。
- **档案**：详细信息里有「家当和账」：这户多少钱、存着什么、谁欠谁、最近六笔买卖。
- **自检**：`?sim=秒` 的结果里有 `data-econ`：
  - 铜钱是否守恒（村里总数 = 开局 + 进村 − 出村）；
  - 断粮的户、买不成的原因；
  - 每天成交几笔，付钱、以物易物、赊账、接济各几笔；
  - 缺口、各户家底，以及最近的账。

  30 天快进：守恒，没有断粮，每天二三十笔买卖。穿模、堵路和不带买卖时持平。

## 新来的人（`life/newcomers.js`、`ui/newcomer.js`）

## 自检（每次改布局后跑）

`node check.mjs` 会输出 `audit=`，四项都应为空（另有 `coplanar.left` 应为 0）：
- `floating`：贴地摆放的东西，底下四角的地面低了一截（悬空）
- `unreachable`：某个院子从门外走不到的房门 / 干活位置 / 井
- `islands`：和井不连通的路网节点（附近的地面高度一并列出）
- `brokenEdges`：走不通的路（沿线每 0.5 米的地面高度，`#` = 挡着）
- `coplanar`：共面闪烁（z-fighting）。建村时（`coplanar.js`）把所有方块的面、棱柱的顶面 / 底面 / 侧面、贴花算到村子坐标，
  找"朝向相同、相距不到 4 毫米、投影有重叠"的面对（门柱和墙、墙的拐角、墙头和压顶、交叉的石板路……第一次查出 657 处），
  同一平面里按面积从大到小排，最大的不动，其余的只把这一面往外推 1.2、2.4……厘米（柱子径向撑粗、贴花沿法线挪），
  修完再查一遍，`found` 是修之前、`left` 是修之后。
- `perchFix`：猫、喜鹊的落脚点从上往下打射线贴到真实表面（屋面、墙头、缸沿、树冠），列出改动过的点；再沿每一跳往下探，算出哪两处之间跳得过去、弧线要多高（有跳不过去的点也列出来）

院子都放在自己的平台以内：广亮大门的门楼缩在墙线里，杂货铺门口的缸和凳子在平台上；
每个院门外铺一块和院里一样高的门前平台，接到路网节点；路只能压平台外沿、不能压平台核心。

## 门

院门（广亮门、随墙门、柴门、作坊的木板大门）和栅栏门（羊圈、菜园）都能开合。门洞是导航里的"门格子"：
关着时动物过不去；人走到门前会停下推门，门开了才过；赶着的牲口没过完门就一直开着。
狗、猪、羊、驴、牛会把门拱开（偶尔溜出院门转两圈再自己回来），但不会关——门就敞着，直到有人从门口过顺手带上。
鸡鸭不会拱门，门敞着时也只在自己的地盘里转。石磨、碾子只有上扇磨盘 / 碾滚和拉杆转，底座不动。

## 渲染开销（`?perf=1`）

`Q='?perf=1' node check.mjs index shots/perf` 输出一行 `perf=`：draw call、三角面、着色器程序、贴图、材质数，按类别（村民、动物、合批的静态场景、实例化的庄稼野花、会动的物件、精灵）分的网格数和三角面。

已经做的优化（秋天村子一帧：draw call 587 → 439，三角面 236 万 → 103 万，贴图 145 → 65，材质 155 → 75）：
- 阴影隔一帧重画一次（`renderer.shadowMap.autoUpdate = false`，主循环里隔帧置 `needsUpdate`）。
- 玉米叶子只用一排体素（一丛 1372 → 954 面）。
- 静态的房子、墙、道具按材质合批（`bakeStatic`），整个村子 60 个 draw call。
- 体素网格贪心合并（`voxelGeometry`）：同一层、同朝向、同颜色挨着的面拼成一个矩形。人从 10 万面降到 2 万，动物 3.9 万 → 1.5 万。
- 庄稼、路边野花不生成朝下的面（`voxelGeometry` 的 `skip: [FACE.ny]`）：叶子、穗子底下镜头永远看不见。庄稼 111 万 → 94 万面，画面不变。
- 庄稼稀一点：谷子一米一丛、高粱玉米一米半一丛、白菜一垄隔一垄（村子里白菜原来 1337 棵、27 万面，是庄稼里最费的）。庄稼 94 万 → 67 万面。
- 进 XR 时阴影贴图 4096 → 2048（两只眼各画一遍；一格影子差不多就是场景里一个像素），退出 XR 换回 4096。
- 烟（`fx.js` 的 `SmokePool`）：所有烟囱的烟团按 5 种形态分进 5 个实例化网格（原来一团一个网格，160 个 draw call），同一组颜色的烟共用贴图和材质。
- 庄稼、野花、石头都是实例化网格。

还剩的大头：庄稼（细长的体素合并不了多少，约 124 万面，玉米一丛 1372 面）；村民每人 5～6 个网格（身子、腿、胳膊分开动，约 160 个 draw call）；
阴影每帧重画（投影的东西约 300 个）。可以再降：庄稼换成更简的形状、远处的庄稼隔一丛画一丛；阴影隔一帧更新一次；村民的两条腿合成一个网格（走路时腿用顶点动画）。

## 防穿模（`nav.js`）

- 0.25 米导航网格：房子、墙、栅栏、道具、树干按真实朝向投影成障碍；高差 > 0.35 米（石堰）不能走，0.3 米台阶能走；水只有鸭鹅能下；鸭鹅还能跳 1.5 米以内的坎。
- `Q='?sim=330&time=15' VT=150000 node check.mjs index shots/sim`：后台快进模拟，输出站进障碍的次数（按人 / 活动归类）、圈养牲口跑出院子的次数（escaped）、门被推开的次数。
- 模拟输出里的 `ms` 是这段模拟实际花了多少毫秒（几乎全是寻路）；`tris` 是当前沙盘的三角面数。动物找不到路的目标 10 秒内不再重找（以前狗、跟着羊倌的羊碰上走不到的目标会每帧搜一遍全图，一帧几十毫秒；改了以后同样的模拟快了六倍）。
- 干活时站在物件跟前、脸朝物件；工具按家伙分动作（锤子砸、锯子拉、锄头锄、勺子搅、扫帚扫……），握在手里朝前伸。`cast.html?only=id,id&pose=work&zoom=7` 放大看。

## 灯光（`daylight.js`）

- 午后 → 黄昏 → 掌灯 → 月夜，太阳、天光、天空、远山跟着变。
- 天黑后：窗户亮（家里有人、在做饭更亮）、灯笼和光晕亮、小六子挨个点路口火把（火苗 + 光晕 + 地面光斑），戏台 / 杂货铺 / 铁匠炉 / 桥头有真实点光源。
- 灯笼、窗户打到四周的光用暖黄（`GLOW.lamp`），不用灯笼本身的橘红；光晕贴图也偏黄——叠加混合，几盏叠在一起就是一片红。西沟的磨坊、山神庙两盏灯只照门口一小片（山神庙那面崖是红石头，光铺开了整面崖都发红）。

## 种植养殖（`farmland.js`）

- 梯田里种着体素庄稼（实例化），按垄种（一米两垄，留一道垄沟，高秆的一米一丛）：谷子（三棵一丛）、红高粱、干了的玉米、白菜，
  茬地里麦个子一行行错开立着，村西坡最高那几级是赵家的大豆；溪南的河滩不种地，是草滩；地皮是一垄垄的松土和谷茬（`furrow` / `stubbleW`）。稻草人、看青棚。西沟用同一套。
- 各家：牛棚、驴棚、猪圈（朝院子那面墙开一扇木栅门，猪拱开出去溜达还能回来；喂猪时猪只凑到槽里边这一侧）、鸡窝、兔笼、鸭棚、蜂箱、菜园、玉米架、羊圈和羊棚。

## 体素人物和动物（`voxel.js`）

- 人：用 `characters.js` 画的正 / 侧 / 背三视图做视觉外壳雕刻，表面取对应视角的像素颜色；腿、胳膊、手持物拆开绕关节转。
- 动物：侧视图按到轮廓的距离"充气"出厚度，按 Q 版比例放大。猪和牛例外：照"我的世界"用方块拼（身子、头、鼻子、四条方腿、牛角），见 `voxel.js` 的 BOXY。
- 树：隐函数体素（椭球 + 噪声），按朝夕阳的程度分档上色。

## XR 里像素风的规则

1. **统一像素密度**：所有贴图按 TPU 绘制，方块 UV 以米计。
2. **在材质里做像素化，不用屏幕后处理**：`EffectComposer` 不支持 WebXR；`pixelize()` 改写采样，硬边、头动不闪。
3. **色相偏移的色阶** 替代后处理调色；**自发光 + 像素光晕** 替代 bloom；**远山大气透视** 替代景深。
4. **统一描边**：方块用反向外壳、精灵用像素描边，同色同粗。
5. **动画按像素一格一格走**。
6. **精灵统一朝向**：每帧按头的位置算一次，左右眼一致；人物按"相对观察者的走向"选正 / 背 / 侧面帧。
7. **静态合批**：上千个方块按材质合成几十批（XR 每个网格要画两遍）。

## 扩展

- 加人：`residents.js` 里加一条（外观字段见 `characters.js` 顶部），`day` + `MORNING` 决定他每天去哪。
- 加活动：`life/events.js` 的 `EVENTS` 里加一条（时间、地点、角色、去的概率）+ `EVENT_ACTS` 里写去了干什么，再加进 `ORDER`。
- 加院子：`compounds.js` 照现有的写，返回 `spots` 让人能走进去。
- 加动物：`animals.js` 加字符画，在院落的 `animals` 里放。
